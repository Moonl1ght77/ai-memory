# 记忆系统使用说明（给 Joe 看的）

> 最后更新：2026-07-07
> 一句话总结：你平时几乎什么都不用做，规则已经写进 Claude Code 和 Codex 的全局配置里，AI 每次开工自动读记忆、收工自动存档。

## 日常怎么用

在项目文件夹里打开 Claude Code 或 Codex，直接说任务就行。AI 会自动：

1. **开工**先读这个项目的三份记忆（知道项目是什么、做到哪、有什么坑）
2. **收工**自动筛选值得记的内容存进记忆，并给你一张【记忆存档回执】

看到回执 = 存档成功。没看到回执 = 问它一句"存档了吗？"

## 只需要记住三句话

| 什么时候 | 对 AI 说 |
|---|---|
| 开一个新项目 | "这是新项目【名字】，帮我建记忆" |
| 不确定刚才存档没有 | "刚才的工作存档了吗？给我回执" |
| 每个月一次 | "帮我做记忆体检" |

## 记忆存在哪、怎么看

所有记忆都是普通的 Markdown 文本文件，就在：

```
E:\AI-Memory\vault\20-项目记忆\<类目>\<项目名>\
```

两种查看方式：
- **Obsidian**：打开库 `E:\AI-Memory\vault`（和以前一样）
- **文件管理器**：直接双击打开 md 文件看

每个项目固定三个文件：
- **项目地图** —— 这个项目是什么、在哪、有什么原则
- **当前进度** —— 做到哪了、下一步干嘛
- **踩坑记录** —— 踩过的坑，别再踩

## 记的内容怎么被复用

不用你操心。AI 每次开工自动读这三个文件，所以：
- 上次做到哪，它接着做（当前进度）
- 上次踩过的坑，它自动绕开（踩坑记录）
- 项目的固定规则，它自动遵守（项目地图）

换平台也一样：Claude Code 记的，Codex 能读到；反过来也一样。因为两边读写的是同一批文件。

## 换电脑（家 ↔ 公司）

记忆库通过你的 GitHub 私有仓库自动同步（Moonl1ght77/ai-memory，只有你能看到）：
- AI 开工自动拉取最新记忆，收工自动上传，你不用做任何事
- 唯一要求：**换电脑前看到【记忆存档回执】再走**，保证这台的更新已经传上去
- 公司电脑第一次使用：照着 `30-工作流\异地电脑接入指南.md` 做，只有三步，其中两步是装软件

## 知识库怎么长出来（防止变水桶）

`40-知识库\` 里按三大类目各有一个文件：微信小程序、独立站、电商作图。

进入门槛故意设得很高（**晋升制**）：
- 一条经验第一次验证成功 → 只留在那个项目的踩坑记录里
- 同一条经验在**第二个项目**再次用上 → AI 才会把它提炼成"场景→做法→出处"写进类目知识库
- 每次"记忆体检"会修剪：过时的、一年没用的条目，报你确认后删掉

所以知识库只会慢慢长，不会变成什么都往里扔的水桶。如果你觉得某条经验特别值得，不想等第二次验证，说一句：**"这条晋升到知识库"**。

## 怎么确认系统在正常工作

三个信号：
1. **每次收工有回执**。AI 完成实质工作后应主动给【记忆存档回执】，没给就要。
2. **每月记忆体检**。它会检查：路由表和文件夹对不对得上、哪些项目进度超过 30 天没更新、有没有写串项目。
3. **git 历史**。每次存档 AI 都会自动做一次 git 提交并上传 GitHub（你不用懂 git），想查"AI 到底改了什么"，说一句"给我看最近的记忆改动记录"。改错了也能回滚，两台电脑都一样。

## 如果 AI 好像没读记忆

新开的对话里 AI 表现得什么都不知道时，说一句：

```
先读 E:\AI-Memory\vault\INDEX.md，这次项目是【名字】
```

这是唯一需要手动的兜底话术。
