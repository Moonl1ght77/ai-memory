## Caveman — 省 token 说话模式（自动激活，无需手动开）

- **状态**: 两台电脑都已装 ✅（家用 / 公司 2026-07-13）。装好即每次会话自动生效，Joe 不需要记得开
- **作用**: AI 回复压缩成电报体，省约 65% 输出 token；代码、命令、报错原样保留
- **可见信号**: Claude Code 状态栏有 [CAVEMAN] 徽章 = 正在生效。两台机器徽章都已配好：公司电脑因状态栏被 claude-hud 占用，用合并脚本 `C:\Users\Administrator\.claude\statusline-hud-caveman.ps1`（徽章写行首 + claude-hud 原样跟后，插件版本哈希路径动态解析，升级不用改），settings.json 的 statusLine 指向它
- **开关**: 说 "normal mode" 临时关；`/caveman lite|full|ultra` 调强度
- **按需命令**（这些才需要记）:
  - `/caveman-stats` —— 看本次会话省了多少 token
  - `/caveman-commit` —— 生成简洁提交信息
  - `/caveman-help` —— 忘了命令就打这个
- **仓库**: https://github.com/JuliusBrussee/caveman
- **另一台电脑安装**: `claude plugin marketplace add JuliusBrussee/caveman` 然后 `claude plugin install caveman@caveman`

## Ponytail — 最简代码模式（自动激活，无需手动开）

- **状态**: 两台电脑都已装 ✅（家用 / 公司 2026-07-13）。装好即每次会话自动生效，Joe 不需要记得开
- **作用**: AI 写代码前先走七级阶梯（要不要写 → 复用现有 → 标准库 → 平台原生 → 已装依赖 → 一行 → 最少代码），防过度工程；官方实测代码量 -54%、成本 -20%、耗时 -27%
- **开关**: 说 "stop ponytail" 临时关；嫌它砍功能砍太狠，直接说"要完整版"
- **按需命令**（这些才需要记）:
  - `/ponytail-review` —— 审当前改动，找过度设计
  - `/ponytail-audit` —— 全仓库扫臃肿，列出可删可简化的
  - `/ponytail-debt` —— 列出代码里所有 `ponytail:` 偷懒标记（欠的债）
  - `/ponytail-help` —— 忘了命令就打这个
- **和 Caveman 关系**: 互补不冲突。Caveman 管说话省字，Ponytail 管代码省行，两个同时跑
- **仓库**: https://github.com/DietrichGebert/ponytail
- **另一台电脑安装**: Claude Code 里 `/plugin marketplace add DietrichGebert/ponytail` 然后 `/plugin install ponytail@ponytail`
