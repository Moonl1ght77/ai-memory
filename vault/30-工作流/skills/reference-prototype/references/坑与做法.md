# 坑与做法

通用一节两种模式都看，再看对应模式那一节。新坑先记进项目踩坑记录，下个项目再验证一次有效，再搬进这里。

## 通用

- 参考站动效靠读代码（`scripts-*.js`、样式表、筛选脚本），截图看不到。有反爬或要登录、读不到就换下一个。Node 24 抓外网要走代理时设 `NODE_USE_ENV_PROXY=1`。
- 内置浏览器面板在后台时动画暂停、截图停在第一帧：用脚本查状态（类名、计算样式、动画进度），动效手感留给 Joe 判断。
- 付费字体找免费近似款。商品图、场景图先用色块加轮廓占位，交付时说明最终观感要等实拍图。

## 新原型（单文件网页；Lorenzo、3D 试穿 Hero 两次验证）

- 本地预览要另包 head：`<meta charset="utf-8">` 和 viewport。
- Artifact read 带 `path: "index.html"` 取回的页面带平台外壳（doctype、head、body）：重发前去掉外壳，只留 `<title>` 起到 `</script>` 的原文；本地预览直接用带外壳的版本。
- 转场、菜单、计数这类动画回调都加超时兜底。
- 弹窗遮罩和抽屉遮罩用不同的类名。

## 借鉴（改现有代码；织花云 2026-11-03 一次使用，待下次验证）

- 新变量挂 `:root` 和现有各外壳根上；外壳上已有同名旧变量时，挂在同一元素上、让新文件后加载就能压过。站长台这类自带一套变量的界面不动。
- 默认按钮换成品牌色后，逐页数一屏里的主色按钮，多出来的降为次按钮。
- 小按钮补点击区：按钮设 `position: relative`，`::after { content: ""; position: absolute; inset: min(0px, (100% - 44px) / 2); }`（百分比按按钮自己的宽高算，大按钮得 0）。
- 预览用项目自带的合成数据预览（临时数据、桩模型、不读 `.env`）。Playwright 逐页查：横向溢出、控制台报错、站外请求、字体实际加载、Tab 走一遍的焦点环、点击区、一屏主按钮数；桌面 1440、手机 390 的截图发给 Joe。
- 新组件还没有页面用时，用 `page.route` 在预览同源路径上 fulfill 一页静态样张（引打包后的 CSS）再截图；样张不进仓库。截长图时固定定位的提示条会浮在页面中间。
- 演示模式会自动登录的项目，真实的登录弹窗打不开，只能用同结构的样张验，交付时写明。
- 自托管字体：官方源文件只放本机临时目录、不进仓库；按 unicode-range 切 woff2，交给打包器带哈希；按许可在页脚署名。
- 工作区是 CRLF（`autocrlf=true`）时，脚本做多行精确替换要按文件原来的换行匹配；单处改动用 Edit 工具最稳。
