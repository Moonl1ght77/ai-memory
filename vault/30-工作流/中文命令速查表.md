# 中文命令速查表

> 给 Joe 看的。他不懂英语，技能描述全是英文看不懂，这份表是中文版菜单。
> 2026-08-05 建。AI 每次装/删技能后要同步更新这张表。

## 怎么用

- **打命令**：输入 `/` 加命令名，比如 `/grill-with-docs`
- **不打也行**：标「自动」的，正常说话 AI 会自己用上；标「手打」的必须你打
- **忘了叫什么**：直接问 AI「有没有能干 XX 的」

## 一、想清楚要做什么（动手之前）

| `/grill-with-docs` | 认真聊需求 | **最常用**。想做个功能但说不清细节。AI 一次问一个问题，每问附推荐答案，你只要说行或不行 | 手打 |

**这四个连起来是一条流水线**（对 Joe 特别有用，因为每步都留下他能读的文档）：

```
/grill-with-docs → /to-spec → /to-tickets → /implement
   聊清楚要什么     变需求文档    拆成小任务      一条条做
```

## 五点五、抓网络内容（Agent Reach，2026-08-05 装）

不用打命令，**直接说要抓什么**，AI 自己会用。

| 你说 | 能不能用 |
|---|---|
| 「帮我读一下这个网页 <网址>」 | ✅ 已通，实测过 |
| 「这个 RSS 更新了什么」 | ✅ 已通 |
| 「B站上搜一下 XX」 | ✅ 只能搜，看不了视频内容 |
| 「小红书上 XX 怎么讲的」 | ⚠️ **要先装浏览器扩展**，见下 |
| 「YouTube 这个视频讲了啥」 | ❌ 缺 yt-dlp |
| **谷歌地图商家信息** | ❌ **Agent Reach 不支持这个平台** |

**解锁小红书**（Joe 自己操作，AI 不能代做）：
1. Chrome/Edge 装 OpenCLI 扩展 https://chromewebstore.google.com/detail/opencli/ildkmabpimmkaediidaifkhjpohdnifk
2. 浏览器登录小红书，保持开着
3. 之后直接说「小红书上搜 XX」即可。**全程不用贴 Cookie**

同一个扩展也顺带解锁 Twitter、Reddit、Facebook、Instagram。

## 重要配置：to-spec / to-tickets 的落盘位置（2026-08-05 定）

这两个技能原本要求先跑 `/setup-matt-pocock-skills` 配置 issue tracker。**那个向导不能跑**（会往每个项目写配置抢记忆库地盘），所以在这里直接把 tracker 定义好，AI 照这个执行，不要问 Joe、不要跑向导：

- **需求文档**（`/to-spec` 产出）→ 项目根目录 `docs\需求\<功能名>.md`
- **任务清单**（`/to-tickets` 产出）→ 项目根目录 `docs\任务\<功能名>-01.md`、`-02.md`…，一个任务一个文件
- **不用 triage 标签**，Joe 没有 issue 系统，任务状态直接在文件里写「未开始 / 进行中 / 已完成」
- 这些文件**归项目不归 vault**，理由同 CONTEXT.md——要跟着代码走
