# 记忆系统位置

## Basic Memory
- 项目名：`joe-memory`
- 记忆库：`E:\AI-Memory\vault`
- 配置目录：`E:\AI-Memory\basic-memory-config`

## Obsidian 查看方式
在 Obsidian 中选择打开文件夹作为库，然后选择：

`E:\AI-Memory\vault`

## 使用原则
- 这个库是 AI 长期记忆库。
- 它不替代小程序 Obsidian 库，也不替代独立站 Obsidian 库。
- 人看的标题和正文用中文。
- 机器检索用的 `permalink` 保持英文稳定 ID。

## MCP 验证结论
- Codex 设置页里已启用 `basic-memory` MCP server。
- `basic-memory mcp --transport stdio --project joe-memory` 可以正常完成 MCP 握手。
- MCP server 实际暴露了 `read_note`、`search_notes`、`list_memory_projects`、`write_note` 等工具。
- 如果某个 Codex 线程的工具列表里看不到 Basic Memory 工具，不代表记忆库坏了；优先判断为当前线程工具下发/发现层没有暴露该 MCP。

## 兜底读取方式
当 MCP 工具未暴露时，仍然按以下方式读取同一套记忆：

```powershell
$env:BASIC_MEMORY_CONFIG_DIR='E:\AI-Memory\basic-memory-config'
uvx basic-memory tool read-note 'joe-memory/20-projects/sku-image-workbench/context' --project joe-memory --local
uvx basic-memory tool search-notes 'sku-image-workbench progress bugs' --project joe-memory --local
```

也可以直接读取 `E:\AI-Memory\vault` 里的 Markdown 文件。
