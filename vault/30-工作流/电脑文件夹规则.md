# 电脑文件夹规则（一共五个地方 + 一个乱区）

> 最后更新：2026-08-09（新增 `E:\Tools\`）
> 核心思想：**不要求你变勤快，只要求乱得有地方**。全电脑只允许一个乱区（00-收件箱），AI 定期帮你清。

## 一、六个固定地方

| 位置 | 放什么 | 一句话规则 |
|---|---|---|
| `E:\Projects\` | 正式项目（代码、网站、小程序） | 一个项目 = 一个文件夹 |
| `E:\Studio-Assets\` | 客户素材、参考图、交付成果 | 格式：`客户名\项目名`，素材永远不和代码混放 |
| `E:\AI-Memory\` | AI 记忆中心 | AI 自动管理，你只看不搬 |
| `E:\Tools\` | 第三方工具的本地拷贝（不是项目） | 别人的仓库、跑一跑就用的工具放这里，**不建记忆、不进路由表、开机同步/收工检查都不扫它** |
| `E:\00-收件箱\` | **全电脑唯一的乱区** | 下载、临时文件、随手保存的，全扔这里 |
| 桌面 | 只放快捷方式 | 不放任何文件和文件夹 |

已存在的老项目（`E:\元提示词agent`、`E:\TVC手册`、`E:\实时原料看盘`、`E:\乐顺科纺程序`）**原地不动**——路径已写进各处配置，搬了反而出错。规则只管新东西。

## 二、新项目标准动线（就三步）

1. 在项目该在的地方建文件夹：代码类 → `E:\Projects\项目名`；纯素材类客户单 → `E:\Studio-Assets\客户名\项目名`（懒得建？直接进第 2 步，让 AI 建）
2. 在这个文件夹里打开 Claude Code 或 Codex
3. 说："**这是新项目【名字】，帮我建记忆**"

AI 会自动完成剩下的：建三份记忆、登记路由表、在项目文件夹放 CLAUDE.md/AGENTS.md。之后这个项目就进入自动记忆循环了。

## 三、对付"下载到桌面"的习惯（一次性设置）

把浏览器默认下载位置改成收件箱，以后想偷懒都偷不到桌面上：

- Chrome / Edge：设置 → 下载内容 → 位置 → 改成 `E:\00-收件箱`
- 微信/QQ 收到的文件：也尽量存这里

做完这一步，桌面从源头上就干净了。

## 四、"帮我收拾电脑"指令（AI 执行规范）

Joe 说"帮我收拾电脑"时，AI 按以下步骤执行：

1. **只读盘点**：列出 桌面、`E:\00-收件箱`、系统下载文件夹 里的所有文件（不动任何东西）
2. **提出去向清单**，按规则分类：
   - 属于某个项目的文件 → 对应项目文件夹
   - 客户素材/图片 → `E:\Studio-Assets\客户名\项目名`
   - 安装包、压缩包残留、明显垃圾 → 建议删除（列出来）
   - 认不出的 → 单独列出问 Joe
3. **Joe 确认后才动手**：移动归位；删除只删 Joe 勾选确认的
4. 输出收拾报告：移了什么、删了什么、还剩什么待定
5. 建议频率：每月一次，和"记忆体检"一起做

## 五、判断文件该放哪的口诀

```
是代码/项目本体？   → E:\Projects\项目名
是别人家的工具？    → E:\Tools\工具名（不建记忆）
是客户的图/素材？   → E:\Studio-Assets\客户名\项目名
是经验/进度/结论？  → 不用你管，AI 写进 E:\AI-Memory
都不是/不知道？     → E:\00-收件箱（反正每月会清）
```
