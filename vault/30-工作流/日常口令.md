# 日常口令（Joe 复制粘贴用）

> 两段固定话术：每天收工一段、异地开机一段。
> Joe 也可以只说短口令「收工检查」/「开机同步」，AI 按本文件对应段落执行。

## 收工检查（每天任务结束，在当天干活的电脑上说）

```
收工检查。今天到此为止，执行：
1. 在 E:\AI-Memory 执行 git status 和今天的 git log，看记忆库有没有没提交、没推送的改动。
2. 读 vault\INDEX.md 路由表，逐个检查"活跃"项目：用项目文件夹的 git log 或文件修改时间，判断今天动没动过。
3. 今天动过、但该项目"当前进度.md"最后更新日期不是今天的：列出来问我补什么，按三问筛选后写入记忆。
4. 今天动过代码的项目：检查项目仓库本身是否已 commit 并 push（异地同步的项目必须推，不然另一台电脑拉不到）。
5. 最后在 E:\AI-Memory 提交并推送，输出【记忆存档回执】；确实没东西可存就输出【本轮无需存档】。
收尾给我一张表：今天动过的项目 / 记忆已更新？ / 代码已推送？
```

## 开机同步（到另一台电脑，开机第一句）

```
开机同步。我刚到这台电脑，执行：
1. 在 E:\AI-Memory 执行 git pull，失败要说明原因，不许默默跳过。
2. 读 vault\INDEX.md 和各活跃项目的"当前进度.md"，找出最近 3 天有更新的项目。
3. 这些项目里，本机有对应文件夹且是 git 仓库的，逐个 git pull 拉最新代码；本机没有的项目标注"本机无"。
4. 扫 vault\30-工作流\已安装工具清单.md，本机缺装的工具提醒我。
5. 只同步和汇报，不改任何文件。汇报格式：另一台电脑最近干了什么（按项目一句话）/ 今天建议从哪继续 / 有没有阻塞点。
```
