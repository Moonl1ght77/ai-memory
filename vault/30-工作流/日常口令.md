# 日常口令（Joe 复制粘贴用）

> 两段固定话术：每天收工一段、异地开机一段。
> Joe 也可以只说短口令「收工检查」/「开机同步」，AI 按本文件对应段落执行。

## 收工检查（每天任务结束，在当天干活的电脑上说）

```
收工检查。今天到此为止，执行：
1. 在 E:\AI-Memory 执行 git status 和今天的 git log，看记忆库有没有没提交、没推送的改动。
2. 读 vault\INDEX.md 路由表，逐个检查"活跃"项目：用项目文件夹的 git log 或文件修改时间，判断今天动没动过。
3. 今天动过的项目：按三问筛选，只有值得记的新事实或状态变化才更新记忆及"最后更新"日期；缺少事实来源时列出来问我，没有新事实不刷新日期。
4. 今天动过代码的项目：检查项目仓库本身是否已 commit 并 push（异地同步的项目必须推，不然另一台电脑拉不到）。
5. 最后在 E:\AI-Memory 只提交本次实际记忆差异，并检查需要同步的未推送提交，按授权推送。输出【记忆存档回执】；确实没东西可存就输出【本轮无需存档】。
收尾给我一张表：今天动过的项目 / 记忆已更新？ / 代码已推送？
```

## 开机同步（到另一台电脑，开机第一句）

```
开机同步。我刚到这台电脑，执行：
1. 在 E:\AI-Memory 执行 git pull，失败要说明原因，不许默默跳过。
2. 读 vault\INDEX.md 和各活跃项目的"当前进度.md"，找出最近 3 天有更新的项目。
3. 这些项目里，本机有对应文件夹且是 git 仓库的，逐个 git pull 拉最新代码；本机没有的项目标注"本机无"。
4. 按本次接手任务读取 vault\30-工作流\已安装工具清单.md 的相关段落，核对本机工具，缺装的提醒我；公司机与家用机的路径、版本分别核对。
5. 对比 vault\30-工作流\全局配置模板\CLAUDE-全局.md、Codex-全局.md 与本机 ~\.claude\CLAUDE.md、~\.codex\AGENTS.md：列出差异，本机独有内容先核对并保留，不能静默覆盖。已有明确安装或覆盖授权且差异已核清时，按授权执行，不重复问同一授权；其他情况只汇报。
6. 开机同步只拉取和汇报，不自行编辑业务文件或安装工具；Joe 同时明确要求的配置、安装任务按其授权范围执行。汇报格式：另一台电脑最近干了什么（按项目一句话）/ 今天建议从哪继续 / 有没有阻塞点。
```
