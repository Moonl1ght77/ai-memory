# 面料小程序标准交付 SOP

> 服务商资产文档。用途：接单后按此流程走，不再边做边想。

> 标注【乐顺已验证】的条目 = 在乐顺科纺项目实测过的做法；标注【假设】的 = 未经实战，用前留意。

## 一、十步标准交付流程

每步固定四件事：**动作 / 输入 / 产出 / 过关标准**。上一步产出 = 下一步输入。

### 第 1 步 · 客户诊断
- 动作：跑「布行接入问卷五问」——品类 / 地区 / 价格带 / 客户构成 / 爆款三块布；追问核心优势（工厂还是贸易、做了多少年、服务过谁）。
- 输入：一次老板访谈（30-60 分钟）。
- 产出：一页定位纸——目标客户是谁、他们拿这个小程序干什么、品牌定位一句话。
- 过关标准：五问全答 + 定位一句话老板点头。**没过关不进第 2 步。**
- 【乐顺已验证】跳过此步的代价 = 做到一半回头补访谈、结构返工。

### 第 2 步 · 内容盘点
- 动作：收营业执照、Logo、面料数据（品名/成分/克重/幅宽/用途）、色卡、工厂图、认证证书、联系方式；逐项登记"有/没有/质量能不能用"。
- 产出：素材清单表（有什么、缺什么、缺的谁补、什么时候补）。
- 过关标准：清单上每个"缺"都有负责人和期限。
- 铁律：证照类文件单独存放，**永不进 Git**。【乐顺已验证】

### 第 3 步 · 信息架构
- 动作：定页面结构（首页板块顺序 / 分类方式 / 详情字段 / 询盘路径）；画一张站点结构图。
- 基准结构（模板默认，客户无特殊要求就用它）：
  ```
  首页：品牌故事 → 系列展示 → 灵感场景 → 面料产品 → 技术参数/实力 → 询盘入口
  子页：面料分类列表 → 面料详情（主图/色卡/参数/卖点） → 询盘表单 / 样品申请
  ```
- 产出：结构图 + 每板块的内容槽位定义（文案槽/图槽/数据槽）。
- 过关标准：询盘路径从任何页面 ≤2 步可达。

### 第 4 步 · 品牌视觉
- 动作：按品牌故事五要素定规范——面料风格 / 文案走向 / 图片风格 / 氛围定调 / 场景运用；定字体、色板、排版。
- 产出：视觉规范一页纸 + **拍板物 = 用现有素材按规范拼装的成品级首页**（真机可看）。
- 过关标准：老板对着成品页拍板。**占位稿不给老板看；拍板后规范锁死不改。**【乐顺已验证：商家只认成品】
- 铁律：不做单张图的多轮审美迭代。图只需符合槽位规格（尺寸/构图/氛围三条），不追求单张惊艳；缺的图按规格后台补，不卡主线。

### 第 5 步 · 系统配置
- 动作：从模板仓库建新项目（新 AppID + 新云环境），部署云函数、建集合、配后台。
- 产出：可运行的空壳小程序 + 管理后台。
- 过关标准：后台能增删改产品并在前台实时可见。

### 第 6 步 · 内容录入
- 动作：面料参数、图片、视频、文案按第 2 步清单录入；图片走第七节媒体链路。
- 过关标准：抽查 10 个产品，字段无缺、图片清晰、色卡对得上。

### 第 7 步 · 合规配置
- 动作：见第四节合规清单，逐项打勾。
- 过关标准：清单全绿，缺一不提审。

### 第 8 步 · 测试上线
- 动作：权限、表单、分享卡片、消息提醒、后台数据全链路测试；性能按第十节验收；提审发布。
- 过关标准：第十节性能标准全过 + 微信审核通过。

### 第 9 步 · 培训验收
- 动作：教会客户三件事——新增/修改产品、查看和处理询盘、导出数据；给一页操作手册。
- 过关标准：客户自己完整操作一遍，全程不求助。

### 第 10 步 · 年度运营（续费入口）
- 动作：按季度更新（春夏/秋冬上新、展会专题、首页活动）、图片视频制作、数据复盘。
- 产出：每季一次更新 + 每季一页复盘（访问量/询盘数环比）。
- **效果回填**：上线 30/90 天询盘数对比，写回案例库——这是案例"能被验证"的凭证。

### 接手现成项目的变体
十步表倒过来当**体检表**：逐步打勾"已完成/残留/没做"，得出位置地图，只补缺口不重做。【乐顺已验证：乐顺 = 5-8 步先完成、回头补 1/2/4 的接手型案例】

## 三、数据放在哪里

**结论：微信云开发（CloudBase），一客户一环境。**

理由（乐顺已验证）：
- 数据天然存境内，合规零操心；
- 免运维、免服务器、自带 CDN 和 HTTPS；
- 小程序端直连，开发链路最短；
- 按量计费，单客户月成本低（基础套餐内基本够用）。

标准集合设计（模板固定，字段可扩展）：
```
products      面料产品（品名/编号/成分/克重/幅宽/用途/卖点/主图/状态）
colorCards    色卡（产品关联/色号/色名/hex/图片fileID）
inquiries     询盘（称呼/电话/需求/备注/时间/状态/负责人）
home_content  首页云配置（板块内容整键覆盖，换季不发版）【乐顺已验证】
merchants     商家账号（OpenID/角色/通知开关）
```

云存储目录规范：
```
products/{产品编号}/v{版本号}/main.jpg      主图（版本化路径，防缓存脏读）【乐顺已验证】
products/{产品编号}/v{版本号}/color-{色号}.jpg
home/{板块}/xxx                             首页素材
```

## 四、必须处理的合规清单

| # | 事项 | 说明 |
|---|---|---|
| 1 | 小程序备案 + ICP | 主体资质、类目选对（纺织面料属一般商贸类，无需特殊资质；出现"医疗/功能性宣称"文案才会触发资质问题） |
| 2 | 用户隐私保护指引 | 公众平台后台"服务内容声明"里逐项声明实际收集行为：手机号、选图上传、剪贴板、OpenID。**代码改了后台声明必须同步改**【乐顺已验证】 |
| 3 | 隐私同意代码闸门 | 询盘提交前未默认勾选的同意框 + `wx.openPrivacyContract` 展示协议 + `wx.requirePrivacyAuthorize` 授权，未同意不写库；纯浏览不弹窗【乐顺已验证】 |
| 4 | 数据境内存储 | 云开发天然满足；如客户要求导出，导出文件不含超范围个人信息 |
| 5 | 证照隔离 | 营业执照/身份证等只在备案时使用，单独目录存放，不进 Git、不进云存储公开目录【乐顺已验证】 |
| 6 | 虚构护栏 | 页面文案：灵感情绪可编，事实（产地/工艺/认证/年份/数据）不可编；AI 成衣图标注"效果示意"【乐顺已验证】 |
| 7 | 无支付则无资质负担 | 询盘展示型不接微信支付，避开支付类审核；将来接支付再补 |

## 五、标准技术架构（前期 · 单客户阶段）

**原则：结构进代码，内容进云配置。**【乐顺已验证——换季/换文案不发版】

```
miniprogram/
├─ config/
│  ├─ runtime.js        全部魔法数字唯一来源（尺寸档位/时长/缓存TTL）
│  └─ home-content.js   首页默认内容（纯数据，可单测；云端 home_content 可整键覆盖）
├─ domain/              纯函数业务规则（媒体规则/视图模型/布局），无 wx API，可 Node 单测
├─ services/            云服务封装（媒体服务/数据仓库），wx API 只出现在这层
├─ pages/               页面（薄，只做绑定和交互）
└─ tests/               Node 原生 test runner，纯函数全覆盖
```

- 页面不直接调 `wx.cloud`，一律走 services 层——将来换存储/换后端只动一层。
- 测试策略：domain + config 纯函数 Node 测试（乐顺 77 条），页面靠契约测试 + 真机验收。
- 每客户一个 Git 仓库，从模板仓库 fork/复制起步；模板自身改进要回流模板仓库。

## 六、SaaS 平台化：决策点，现在不做

**触发条件（同时满足才启动）：**
1. ≥3 个成熟付费案例在线运行；
2. 年度运营续费真实发生（有人为第四层付钱）;
3. 每客户一环境的维护成本开始吃掉利润（同一个 bug 要修 N 遍）。

**触发前**：多客户 = 多仓库多环境，模板仓库是唯一公共资产。改进只做在模板里，新客户享受，老客户大版本升级时跟进。

**触发后的迁移路径**（【假设】未实战）：
统一管理后台（一处登录管所有客户）→ 数据结构版本化 → 配置驱动换肤（客户差异全部收进配置）→ 最后才考虑单实例多租户。

**警告：跳过触发条件提前做 SaaS = 用真金白银给假设买单。**

## 七、媒体资源链路

### 图片（核心认知：云开发自带实时图片处理，MVP 不需要预生成派生图）

上传管线（MVP，云函数或后台直传）：
```
上传原图
  ↓ 校验：类型 jpg/png/webp、单张 ≤10MB、可读性验证（下载回读确认非损坏）【乐顺已验证】
  ↓ 保存原图到版本化路径 products/{编号}/v{n}/...
  ↓ 写入媒体记录（fileID/尺寸/用途）+ 保存后回读核对【乐顺已验证】
完成。派生图不预生成。
```

展示端（实时派生，乐顺已验证四档）：
```
临时地址 + imageMogr2 参数实时缩图：
  列表 720 / 搜索缩略 480 / 详情 1280 / 色卡条 240
  加 /format/webp 转 WebP（客户端广泛支持）
原图只用于"点击查看高清"场景。
临时地址缓存 1 小时存 storage，全页面共享。【乐顺已验证】
```

预生成派生图（你贴的完整管线）什么时候才需要：流量大到实时处理费用超过存储费用，或需要秒开的极端场景。早期客户不多时不做。

### 视频

MVP（【乐顺已验证】的教训：20.6MB 原片直挂首页 = 卡顿投诉根源）：
```
交付前人工转码（剪映/ffmpeg 导出）：720p H.264 MP4，目标 ≤10MB
  ↓ 上传云存储 + 单独上传一张封面图
  ↓ 前端：默认只挂封面；WiFi 自动播 / 移动网络点击播放【乐顺已验证】
```
自动化转码管线（腾讯云 VOD：转码/封面/多码率自适应）：等年度运营客户 ≥2 家、视频更新成为常态再上。【假设】

## 八、前端加载策略

| 策略 | 标准做法 | 状态 |
|---|---|---|
| 首屏只加载必要资源 | 首屏 = Hero 一屏内容；折叠线以下板块延迟渲染 | 【乐顺已验证】画廊分批加载 |
| 图片懒加载 | `<image lazy-load>` 原生属性，全站默认开 | 原生能力，零成本 |
| 分页 | 列表每页 20 条，触底加载下一页 | 标准做法 |
| 虚拟列表 | 单列表 >200 条才上 recycle-view，之前分页够用 | 【假设】面料 SKU 通常几十条，多数客户用不到 |
| 占位图/骨架屏 | 图位固定宽高比 + 底色占位防抖动；首页骨架屏可选 | 色卡无图回退色值占位【乐顺已验证】 |
| CDN | 云开发临时地址自带 CDN，无需自建；配合临时地址缓存 1h | 【乐顺已验证】 |
| 开屏 | 启动页 ≤1 秒 | 【乐顺已验证】2s→1s |
| 弱网退化 | 视频退化为封面图点击播放；图片走低档缩图 | 【乐顺已验证】 |

## 九、性能验收标准（第 8 步测试上线用）

- [ ] 进入首页立即有画面，无长时间空白
- [ ] 首屏先显示封面，视频不阻塞页面
- [ ] 普通网络首屏约 1–2 秒可用
- [ ] 产品列表分页加载
- [ ] 缩略图单张 ≤150KB（720 档 + WebP 可达）
- [ ] 详情主图单张 ≤400KB（1280 档 + WebP 可达）
- [ ] 首页视频 ≤10MB
- [ ] 弱网自动退化为静态图片
- [ ] 高清资源仅在点击查看时加载
- [ ] 隐私闸门：未同意不写库；纯浏览不弹窗

## 十、与既有工具的挂接

- 第 1 步问卷五问 = 已有「布行接入问卷」第 0 号工具。
- 第 4 步图片生产 = agent全自动生图项目（批量场景走 V12 流水线，精品单图走手工静帧法，按场景选）。
- 案例闭环 = 效果回填后按知识库晋升制入 `40-知识库`。
- 乐顺科纺 = 本 SOP 第一个接手型验证案例。
