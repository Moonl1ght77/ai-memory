# 异地电脑接入指南（公司电脑 / 新电脑）

> 目标：让另一台电脑和这台一样——AI 自动读记忆、自动存档、自动和 GitHub 同步。
> Joe 只需做第 1、2 步（一次性），第 3 步交给 AI。

## 第 1 步：装软件（一次性）
1. 安装 Git：https://git-scm.com/download/win（一路下一步即可）
2. 安装 Claude Code 和/或 Codex（和家里一样的方式）

## 第 2 步：把记忆库下载到这台电脑（一次性）
打开命令行（Win+R 输入 cmd 回车），逐行执行：

```
git clone https://github.com/Moonl1ght77/ai-memory.git E:\AI-Memory
```

- 第一次会弹出 GitHub 登录窗口，用浏览器登录 Moonl1ght77 账号即可（凭据会自动保存，以后不再问）。
- 如果这台电脑没有 E 盘：换个盘符 clone，然后在第 3 步告诉 AI 实际路径，让它调整配置里的路径。

## 第 3 步：让 AI 完成剩余配置（一次性）
在 `E:\AI-Memory` 文件夹里打开 Claude Code 或 Codex，把这句话发给它：

```
这是新电脑接入。请读 E:\AI-Memory\vault\30-工作流\异地电脑接入指南.md，
按"AI 执行部分"完成这台电脑的全局配置，完成后给我回执。
```

## AI 执行部分（AI 看这里）
1. Claude Code 使用当前母版 `30-工作流\全局配置模板\CLAUDE-全局.md`，写入本机 `C:\Users\<用户名>\.claude\CLAUDE.md`。先对比现有文件，本机独有内容必须核对并保留；应进入共同规则的内容按母版规则合并后再覆盖，不能静默丢弃。Joe 已明确授权接入或覆盖且差异已核清时，不重复询问同一授权。
2. Codex 使用当前完整母版 `30-工作流\全局配置模板\Codex-全局.md`，写入本机 `C:\Users\<用户名>\.codex\AGENTS.md`，按同样要求核对本机独有内容；不再使用已停用的 `AGENTS-Codex追加.md` 追加规则。
3. 如果本机记忆库不在 `E:\AI-Memory`：只调整本机全局配置中的记忆根目录，并说明本机对应关系；不能用本机路径覆盖共享母版或 INDEX.md 路由。
4. 项目源码：按需单独 clone 各项目仓库（项目里的 CLAUDE.md/AGENTS.md 已随项目仓库走）。公司机与家用机的实际项目路径分别核对；本机路径如与路由表不同，在本机对话中说明，不替换另一台电脑的路径。
5. 验证：本机实际记忆根目录的 `git pull` 正常、两种全局配置文件存在、按路由读取一个项目的三份记忆成功。
6. 输出【接入回执】：装了什么、改了什么、验证结果。

## 日常同步机制（两台电脑都一样，全自动）
- AI 开工自动 `git pull`（拿到另一台电脑的最新记忆）
- AI 收工按三问筛选，有值得记的新事实才更新记忆及日期，有实际差异才 `git commit`，需要同步的提交按授权 `git push`。
- 两台电脑同时改了同一个文件产生冲突时，先核对两端内容；含义不清就说明待确认，不能静默选一端覆盖。
- **换电脑前让当前电脑的 AI 正常收工**，确认需要推送的改动已同步再换机。
