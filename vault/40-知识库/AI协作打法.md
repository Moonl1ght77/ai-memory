# AI 协作打法

> 跨项目复用的"怎么用 AI 干项目"打法。按知识库规则晋升制维护。

### 【场景】任何新项目/新系统/新业务流水线开工时，防 vibecoding 浅层化
- 做法：写码前先产三件套给 Joe 确认——①价值链一页图（从最终用户倒推到交付，每环谁把关）②能力清单打分（含质检/审核/版本管理/文件规范这类无聊层）③缺口按业务风险排期。配套铁律：同类 bug 修第 3 次=架构信号停止补例；症状级请求修完必须点破层缺失；目标架构进项目记忆每次开工 diff。
- 原因：AI 只答被问的问题——症状级提问得症状级补丁，局部最优累积长不出目标架构；AI 书本级行业知识大多有，缺的是触发时机；实战校准（哪环真翻车）只能靠访谈+实弹反馈挖，配置替代不了。
- 验证：泽鑫飞书作图 2026-08-25（三石九步链 vs 自建 30% 观感的复盘；"回显骗人"栽4次才补质检层的反例）。**Joe 点名晋升，免二次验证。**
- 落地：Claude Code 与 Codex 分别以当前全局母版 `30-工作流\全局配置模板\CLAUDE-全局.md`、`30-工作流\全局配置模板\Codex-全局.md` 为准，执行各自的“新项目与领域校准”规则；同步前核对本机独有内容，不能静默覆盖。
- 已被取代的旧口径（2026-10-08）：2026-08-31 的“Codex 只有记忆系统规则、领域专家模式仅限 Claude”及旧追加模板恢复方法不再作为现行指令。2026-08-31、2026-09-16 曾发现 Codex 全局文件为 0 字节的历史保留；原因未查实，不能据此认定升级会重置。开机同步核对两种全局配置是否存在并符合当前母版。

### 【场景】模型的产出会落进库、拼进提示词、或走进任何后续代码路径时
- 做法：给模型立的规矩，在产出**落地那一步用代码再拦一次**——枚举 / 字段白名单、禁 `--` 这类上游控制参数、判词保护闸。同一个决定只要还有纯代码路径能走到，那条路上必须单独再立一次。
- 原因：提示词里的约束只覆盖模型经手的那条路。模型偶尔不听，纯代码路径根本读不到提示词。实测都是「提示词写了、代码没拦、真漏了」。
- 验证：印花工作台 2026-09-07（判词闸：提示词写「判词高于命中率」，命中率下架路径仍把「复古棉布」下了）；2026-09-08（frag 闸：提示词写「不要 --参数」，`propose()` 没拦，外部评估核对时抓出）；agent全自动生图（只改提示词的修复被后续迭代无声覆盖，改为三点落地，见 `电商作图.md`）。

### 【场景】任何仓库里会放竞品逆向 / 研究资料时
- 做法：建仓那一刻就设私有；AI 开工先 `gh repo view <repo> --json isPrivate` 核一次，公开就先转私有再干活；竞品原件（HTML / JS / CSS / 图 / 复刻原型）不进任何仓，只留自己写的分析与数据表。
- 原因：公开仓等于把「我们在逆向谁」和对方的资产一起挂出去；私有仓也不放对方原件，给合伙人看或泄了都是把柄，放在手边还诱使照抄。
- 验证：印花工作台 2026-08-31（`print-pattern-workbench` 因含 unisevenai 逆向报告定为私有）；2026-09-08（`Joe-Pattern-Weaver` 建成公开仓带 1.2MB 竞品目录，当天转私有，决策 159）。

### 【场景】AI 往 Markdown 记忆 / 文档里写含 Windows 反斜杠路径的文本时
- 做法：优先用当前环境的直接文件编辑工具（如 Claude Code 的 Write / Edit、Codex 的 apply_patch），不经过 Python / JS 普通字符串、`echo -e`、`printf`、heredoc 拼 sed 这类会解释反斜杠的层；确需脚本时用原始字符串（Python `r'...'`）或 `chr(92)` 拼反斜杠。写完检查本次修改文件的路径完整性、制表符和控制字符（排除正常换行）。Claude Code 的 Bash 工具曾出现连写的两个反斜杠被压成一个的问题，替换脚本里别靠双反斜杠表示一个反斜杠。
- 原因：`\n` `\t` `\0` 和 `\03` `\202` 这类八进制序列会被当成转义符：路径断成两行、多出制表符、混进 NUL 和控制字符、`\2026` 变乱码。Markdown 里看不出来，AI 下次照着读就是错路径。
- 验证：英维尔独立站 2026-08-30（`list.join("\n")` 断行）；印花工作台历史归档 2026-09-07（`\03_交接\2026-09-07` 变控制字符加乱码，`\0` 变 NUL）；agent全自动生图 2026-09-15～16（`完全体\solutions\nuv_oauth_login.py`、`街拍线\nuv_apply.py`、`街拍线\out\test1` 共 15 处）。公司机 2026-09-16 一次修 6 个文件，修复时 perl / Python 替换串里的双反斜杠被 Bash 工具压掉，第一次修没落盘，改 `chr(92)` 才成。
