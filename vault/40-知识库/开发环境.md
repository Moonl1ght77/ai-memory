# 类目知识库 · 开发环境

> 跨项目复用的本机/环境类打法。晋升规则见《知识库规则.md》。

### 【排查外网连接问题】curl 通不代表代码通，先查代理
- 做法：本机排查"程序连不上某外网服务"时，第一步 `env | grep -i proxy`。curl/浏览器会自动走系统代理（HTTP_PROXY=127.0.0.1:10808），而程序代码通常裸连——于是出现"我手测明明是通的"假象。确认是代理差异后，给程序注入代理（环境变量/ProxyAgent），或换国内直连的服务端点。
- 原因：这台机器常年挂全局代理，一切"手测通、程序断"的矛盾优先怀疑这个；反过来"程序在本机通"也不代表部署到国内服务器还通。
- 验证：GoodJob外贸CRM定制 2026-08-15，同一天在 AI 通道、数据源通道两处独立复现（Joe 特批晋升，待二次验证）

### 【PowerShell 截取原生命令输出】`| Select-Object -First N` 会提前掐掉上游进程
- 做法：要完整跑完的 node、git、npm 命令，不要直接接 `Select-Object -First N`；先让命令跑完（结果写文件，或 `$out = … | Out-String`），再截取显示。看到退出码 255 或 -1 时，先查是不是截取造成的，再判断命令本身成没成功。
- 原因：拿够 N 行后 PowerShell 会停掉上游原生进程，进程可能来不及写完文件，退出码也会变成 255／-1。
- 验证：织花云 2026-09-25 家用机（node 脚本被掐，结果文件没写出）；黄金CRM 2026-10-11 公司机（`git status` 接截取后退出码 255，同一条命令里的推送实际已成功）
