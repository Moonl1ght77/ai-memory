## 已晋升条目

### 【场景】借参考网站（Awwwards 等获奖站）的设计手法前，先量化拆解
- 做法：本机 Edge 无头 + CDP 脚本逐屏截图并导出 probe（字体、色值令牌、请求数与重量、标题层级、JSON-LD、减少动态规则），再 curl 读 HTML / JS / CSS；每条标「事实 / 推测」，截图里 WebGL 空白只凭源码下结论；每站末尾写「对本项目可借 / 不可借」到参数，最后汇总成预算表和判断清单。并行抓取用系统分配的空闲端口、核 `finalUrl`。
- 原因：获奖站普遍很重（首访 5–53 MB）、多数不处理减少动态、常把字画进 canvas；不量化就会把伤 GEO / 速度的手法搬进来。
- 验证：巡航永恒（2026-11-04～05，11 站，`20-项目记忆\其他\巡航永恒\参考拆解\README.md`）；承泓数字主站（2026-11-08～09，10 站，项目仓 `research\awwwards\00-汇总方法论.md`）。
