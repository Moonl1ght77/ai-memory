# 盲剑卡牌肉鸽 · 项目地图

## 项目定位
Joe 自己玩的类《杀戮尖塔》肉鸽卡牌小游戏。原创主角「盲侠剑客」（气质参照《座头市》）：敌人意图要靠「听」才看清，攒「静」后「拔刀斩」。首版只做一幕打到 Boss。

## 位置
- 项目目录：`E:\Projects\card-roguelike`（英文名，防中文路径问题）
- 设计唯一依据：`design/game-brief.md`；开发任务：`production/epics/blind-blade/`
- 代码：规则 `src/gameplay/combat/`（纯规则类）、界面 `src/ui/`，主场景 `src/ui/battle_screen.tscn`；数值 `assets/data/*.tres`
- 远端：`origin` = 私有仓 `Moonl1ght77/card-roguelike`（2026-10-15 建，主干 main）；`upstream` = CCGS 模板仓（只用于升级框架，别往它推）

## 技术栈
- Godot 4.7（本机 4.7.2 标准版，非 .NET）/ GDScript / 2D / Forward+ / Windows 窗口 1280x720
- 命令行 `godot` 是 `~\.local\bin` 下的 shim，指向 `E:\Tools\Godot\4.7.2\Godot_v4.7.2-stable_win64_console.exe`
- 框架 Claude Code Game Studios 1.1.3，配置在 `project.yaml`
- 窗口 1280x720，拉伸 canvas_items + expand（story-001 定，写在 `project.godot`）
- 规则自检：`godot --headless --path . -s res://tests/unit/combat/fixed_battle_test.gd`（不依赖 gdUnit4，退出码 0 = 全过）
