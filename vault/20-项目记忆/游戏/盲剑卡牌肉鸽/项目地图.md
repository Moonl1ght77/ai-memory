# 盲剑卡牌肉鸽 · 项目地图

## 项目定位
Joe 自己玩的类《杀戮尖塔》肉鸽卡牌小游戏。原创主角「盲侠剑客」（气质参照《座头市》）：敌人意图要靠「听」才看清，攒「静」后「拔刀斩」。首版只做一幕打到 Boss。

## 位置
- 项目目录：`E:\Projects\card-roguelike`（英文名，防中文路径问题）
- 设计唯一依据：`design/game-brief.md`；开发任务：`production/epics/blind-blade/`
- 代码：规则 `src/gameplay/combat/`（纯规则类）、`src/gameplay/cards/`（奖励池、奖励抽取）、`src/gameplay/run/`（一局状态、地图 `ActMap`、悬赏条件）；界面 `src/ui/`，主场景 = 标题页 `src/ui/title_screen.tscn`（点开始切到 `battle_screen.tscn`，它是整局宿主；失败 / 通关复用全屏提示页 `notice_screen`；共享主题 `assets/ui/ink_theme.tres`；地图页 `map_screen`、提示页 `notice_screen`、交易页 `trade_screen`、奖励页 `reward_screen` 都作为子节点挂在里面，敌人块 `enemy_panel.tscn` 按敌人数动态生成）；数值 `assets/data/*.tres`，一场战斗的阵容 = `assets/data/encounter_*.tres`，地图参数 = `assets/data/act_map_config.tres`
- 远端：`origin` = 私有仓 `Moonl1ght77/card-roguelike`（2026-10-15 建，主干 main）；`upstream` = CCGS 模板仓（只用于升级框架，别往它推）

## 技术栈
- Godot 4.7（本机 4.7.2 标准版，非 .NET）/ GDScript / 2D / Forward+ / Windows 窗口 1280x720
- 命令行 `godot` 是 `~\.local\bin` 下的 shim，指向 `E:\Tools\Godot\4.7.2\Godot_v4.7.2-stable_win64_console.exe`
- 框架 Claude Code Game Studios 1.1.3，配置在 `project.yaml`
- 窗口 1280x720，拉伸 canvas_items + expand（story-001 定，写在 `project.godot`）
- 规则自检：`godot --headless --path . -s res://tests/unit/combat/fixed_battle_test.gd`（战斗核心）、`... -s res://tests/unit/blind_mechanics/blind_mechanics_test.gd`（盲侠机制）、`... -s res://tests/unit/cards/card_pool_and_reward_test.gd`（卡池与奖励）、`... -s res://tests/unit/enemies/enemies_test.gd`（敌人阵容）、`... -s res://tests/integration/run/act_map_and_nodes_test.gd`（地图与节点）、`... -s res://tests/integration/run/full_run_loop_test.gd`（整局机器人 + 重开 + 不存档）；不依赖 gdUnit4，退出码 0 = 全过，新克隆先跑一次 `godot --headless --path . --import`
