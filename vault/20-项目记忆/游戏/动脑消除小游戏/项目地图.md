# 动脑消除小游戏（暂名） · 项目地图

## 项目定位
堆叠三消（同类 tile match 机制）小游戏，定位「给爱动脑的人玩」：等 AI 处理的空档来一局，玩完有收获。广告词与游戏内文案都往「动脑、举一反三、脑洞」靠（Joe 2026-11-25 提出）。与「虚拟产品矩阵」（欧美为主、15 天判定）分开立项：本项目主场在国内。

## 平台（Joe 2026-11-25 定）
- 收入主场：微信小游戏（个人主体可做；只靠广告不做内购不需版号；认证 30 元/年；累计 100 独立访客开流量主）
- 试验田：小红书「小工具」（挂笔记下方，静态网页沙箱、离线、无存档、无变现，2026-09 游戏日报报道），用来免费测定位与文案
- 海外：放第二批
- 两边共用一份网页代码

## 技术栈
TypeScript + Vite + Vitest，Canvas 2D 自绘，无引擎、无界面框架、无图片素材（见当前进度）。

## 长期原则
- 开发流程按 Sonic「V2.0 验证驱动」（Joe 2026-11-25 定）：选题及差异化验证 → 确认平台能力及资质 → 核心玩法 Demo → 首局体验及数据埋点 → 审核上线及基础测试 → 种子流量验证 → 按数据迭代或止损。方向不对就及时调整或止损，不往里堆功能。
- 机制可用，「羊了个羊」名字、美术、角色、关卡不用；投广告和搜索关键词也不蹭「羊了个羊」。
- 「动脑、有收获」要靠玩法撑：每关有解、写得出顿悟点（本山德彪做法），不能只换文案。
- 变现以激励视频为主，放在玩家卡住时；不放开屏和强制插屏；道具少送。
- 新游种子 90 天内只能开一次，打磨好再开；行为埋点从第一版就接。
