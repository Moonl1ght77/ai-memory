## 已确认问题
（2026-11-23 核对，来源为各仓库文件和官方文档；还没动手，属于事前查明的坑）
- t3code 体量和速度：HEAD `1368854` 约 190 万行 TypeScript（服务端 78 万、网页端 50 万、手机端 24 万、桌面壳 9 万）；11-19 至 11-22 每天 141–218 个提交，改动集中在几个三四千行的大文件。
- t3code 的 Windows：有 NSIS 安装包和 winget / scoop，但 CI 不含 Windows，`windows-tests.yml` 写明套件在 Windows 上还没有一项通过。
- t3code 扩展成本：新增一个接口至少改 5 个上游文件（`rpc.ts` 三处、`contracts/src/index.ts`、`RpcAuthorization.ts`、`RpcInstrumentation.ts`、`ws.ts`），漏登记编译失败；数据库迁移是单一递增编号，fork 自加编号会和上游撞号，业务数据要放独立数据库文件。
- t3code 上游规则：lint 禁止用 className 改 shadcn 组件样式、未翻译文案报错、禁止持续重绘动画、要求功能覆盖手机端；工具链钉死 Node 26.13.1、pnpm 12。
- t3code 缺的：没有托盘、没有全局快捷键呼出、没有 Mica、字体栈没有中文字体、没有动效库。
- t3code 现成可用的：更新是只提醒不自动下载；`/mcp` 为 HTTP + OAuth（只接受 https 或 localhost），约 100 个工具，含 `t3_thread_launch`（可带项目和首条提示词）；局域网和 Tailscale 远程访问；已有内嵌网页技术（用在预览上）。
- 订阅登录条款：OpenAI app-server 文档写明订阅登录从未允许用于商业或托管服务，替代的 Sign in with ChatGPT 只对选定伙伴开放；Anthropic Agent SDK 文档写明第三方产品未经批准不得提供 claude.ai 登录或订阅额度，只允许运行未改动的 Claude Code、用户自己登录。两人自用可行，对外卖按现文档走不通。
- tldraw：自有许可，不是开源。生产环境没有有效 key 编辑器停止渲染；试用 key 免费 100 天、每个主体一次；hobby key 限非商用且带水印；商业价格不公开。开发环境不用 key。
- Electron 的 Mica：只支持 Windows 11 22H2 及以上，Windows 10 没有回退；无边框 + Mica 有过最大化变黑、圆角丢失的问题（electron #41824、#46753、#48421、#48031），已修但有复发记录。
- 订阅不提供向量接口：本地向量检索要本机模型或 API key。

- 0A 基线（2026-11-23 公司机实测，细节和失败清单在项目仓 `docs\superpowers\baseline\2026-11-23-v0.1.11-windows.md`）：
  - `vp` 装成了「系统优先」模式（`.vite-plus\config.json` 里 `nodeShimMode: system_first`），直接跑 `vp` 用的是系统 Node 24.15.0，不是钉住的 26.13.1；`vp env exec --node 26.13.1` 会把 Node 26 下载到 `.vite-plus\js_runtime\node\26.13.1`，但这种模式下它起的 `node` 仍是 24。可行做法：每条命令开头 `$env:PATH = "C:\Users\Administrator\.vite-plus\js_runtime\node\26.13.1;$env:PATH"`，再用 `vp exec node --version` 确认。
  - Electron 运行时下载不走环境变量里的代理，要加 `$env:ELECTRON_GET_USE_PROXY = "true"`（会话里已有 `HTTPS_PROXY`）。不加就卡在 0 字节。
  - 上游那条 Windows 测试命令遇到第一个失败的包就不再起新包（38 个包只起 7 个），要失败清单得逐包跑 `vp run --filter <包名> test`（约 15 分钟）。`vp run` 没有「失败后继续」的开关。
  - 基线数字：类型检查 0 错；lint 0 错 17 警告；服务端以外 38 个包里 18 个有失败（20 个全过），共 52 个文件、190 个测试不过（其中 `@t3tools/scripts` 有 8 个不是上游问题）；服务端测试 45 分钟跑不完，停掉时已有 19 个文件、193 个测试不过。
