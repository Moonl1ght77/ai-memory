# 实时原料看盘-项目地图

## 项目概述
实时面料原料价格监控面板，用于展示纺织行业原料市场价格行情、涨跌趋势、采购预警等信息。

## 技术栈
- **前端框架**：React 19.2 + Vite 6.4
- **图标库**：lucide-react
- **开发端口**：5173（默认）
- **项目类型**：单页应用（SPA），纯前端原型

## 核心功能模块
1. **顶部工具栏** — 搜索、筛选、刷新
2. **左侧导航** — 品类分类（面料、纱线、纤维等）
3. **KPI 指标条** — 关键数据概览
4. **中央价格表** — 11列市场行情表（品名、规格、最新价、涨跌、7日均价、30日均价等）
5. **右侧洞察面板** — 上游指标、采购预警、接口预留标识

## 数据状态
- 当前使用**模拟数据**
- 数据结构已预留实时接口适配
- 数据源位于 `src/App.jsx` 的 mock 数组中

## 商业情报要点（2026-06-09调研）
### 推荐数据源接入顺序
1. **AKShare（免费）** — 基础现货价格，Python库
2. **openctp-ctp（免费）** — 郑商所期货实时行情
3. **生意社（100ppi）** — 全品类现货价格（5K-50K元/年）
4. **百川盈孚（Baiinfo）** — 化纤产业链深度数据（5K-50K元/年）

### 市场空白
- 无统一纺织原料看板（棉花平台不管化纤，化纤平台不管棉花）
- 移动端体验差
- 无AI价格预测
- UI普遍过时

### 差异化定位
> "纺织采购人员的彭博终端 — 全品类原料价格、AI预测、智能预警，一站式解决"

### 定价策略
- 免费版：0元（基础行情、T+1数据）
- 专业版：2,980元/年（实时数据、3年历史）
- 企业版：9,800-15,000元/年（全功能、AI预测）
- 旗舰版：30,000-100,000+元/年（定制开发）

### 收入预测
- 第1年：432万元（960付费用户）
- 第2年：2,570万元（5,350付费用户）
- 第3年：8,200万元（14,100付费用户）

### 技术栈
- 前端：React 19 + Vite + Tailwind
- 后端：Python FastAPI
- 数据库：PostgreSQL + TimescaleDB
- 缓存：Redis
- 云服务：阿里云
- MVP成本：~715元/月
