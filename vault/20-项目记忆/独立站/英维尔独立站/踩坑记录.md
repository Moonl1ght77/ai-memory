- （2026-08-24，Blender 布料缝合）**`use_sewing_springs` 不是万能的，用错场景比不缝还差**。它的适用场景是 Marvelous Designer 那种"平面裁片平摊在空中 → 缝合弹簧把它们拉拢成立体"。本项目的裁片一开始就已经按人体摆在 3D 位置上了，这时再加缝合力，它会跟已有的钉点、碰撞互相打架：袖子被吸进去拧成一团、衣身被拽皱。另外两个实操坑：① **就近配对必须卡距离上限**，不卡的话总有点配到很远的另一侧，拉出一根横贯整个模型的长弹簧（画面上表现为几根穿出画面的长条）② **缝合边是游离边（没有面），Solidify 会把它们也加厚成可见的尖刺**。**结论**：裁片已在 3D 位就位时，袖窿收口用笨办法更划算 —— **洞开小、袖山放大，两片直接搭接，搭接那几圈全钉死**。缝合的完整实现留在 `sew_lib.py`，将来要做"平面裁片摊开→缝成衣服"的动画时才用得上。

## CSS 3D 环形轮播：backface-visibility: hidden 会剔掉整个后半圈（2026-08-25）

首页分类 3D 环第一版一屏只见 3 张卡，调 opacity/blur 都没用。根因：卡片是 `rotateY(角度) translateZ(R)` 挂环朝外，转到环后半（90°~270°）的卡对观察者露的是**背面**，`backface-visibility: hidden` 直接把它们整张剔除——不是透明度问题。去掉该属性后背面卡以镜像示人，配 blur+压暗读作背景景深层（参考片就是这个效果），一屏 7 张。另两个同场景实测值：透视投影里背面卡会缩聚到画面中部，opacity 低于 0.5 在深底上基本隐身；blur 按半像素量化（`Math.round(x*2)/2`）防每帧重光栅化。

## 拖拽组件里 setPointerCapture 会杀死子元素的 click（2026-08-25）

- （2026-08-30，上线 HTTPS）**云防火墙没放行 443 时，一换命名域名配置会让整站外网全黑，而且服务器上自测全绿看不出来**：Caddy 一旦站点块写成域名就自动开 HTTPS，把 80 的请求全部 308 跳到 443；腾讯云轻量防火墙当初只加了 22/80/Ping，443 的包直接被丢，于是域名打不开；同时按 IP 访问也一起失效（配置只认两个域名，Host 是 IP 对不上任何站点，回 404）。**迷惑点**：服务器本地 `curl --resolve ...:443:127.0.0.1` 返回 200、证书也签下来了、ufw 是 inactive，站内一切正常，只有从外网测 TCP 443（`Test-NetConnection -Port 443`）才暴露是 False。**规避：上 HTTPS 之前先把云防火墙 443 规则加好，再换 Caddyfile**；诊断顺序固定为「服务器本地 curl → 主机防火墙 → 云防火墙 TCP 连通性」，三层分开测才不会误判成 Caddy 配错。

## 2026-08-31 · 报价表成分列有两种写法，猜错就是把成分说错

成分直接张冠李戴，且合计 95% 看着还挺像真的。

272 款里靠这条兜住 2 款脏数据（QW0016 "72% cationic polyester 15% spandex 13%"、
WBCSU0013 混了纱支号），显示得糙一点，但没说错。

## 2026-08-31 · Astro glob loader 会把文件名 slug 化，点被吃掉

博客译文按 `<slug>.zh.md` / `<slug>.bn.md` 命名，取文层按 `/\.(zh|bn)$/` 判语言后缀。

**默认 generateId 会把文件名 slug 化，点直接没了**（how-to-read-gsm.zh → how-to-read-gsmzh），

## 2026-08-31 · 多语言取值的三元表达式只写了两个分支，第三语言会静默拿到英文

`const name = lang === 'zh' ? (product.nameZh || product.nameEn) : product.nameEn;`

看着没毛病，中文页对、英文页对——孟语页落到 else 分支拿英文，而且不报错、不空白，
肉眼扫过去还以为是「品牌名本来就是英文」。三语站里这种两分支三元是个反复出现的形状，
同样的写法当时还出现在 title 和 meta description 上。

做法：**取值收进一个按语言查表的函数**，语言列表在一处，加语言时不会漏
  export const nameOf = (p, lang) =>
    (lang === 'zh' ? p.nameZh : lang === 'bn' ? p.nameBn : '') || p.nameEn;
并且回落一律回落英文（宁可显示英文，也不要空）。

配套判断：**哪些字段该翻、哪些不该翻，要当决定写进注释**。面料成分
（Nylon 88% Spandex 12%）在孟语页保持英文是对的——孟加拉制衣行业规格表本来就走英文，
翻成孟语买手要倒译回去，询盘邮件里也是英文。不写下来，下次体检又会被当成漏翻改一遍。
