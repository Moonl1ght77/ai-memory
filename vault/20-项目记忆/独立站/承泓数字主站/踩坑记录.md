## 风险
- Cloudflare 可能默认替站点屏蔽 AI 爬虫：Messenger（托管在 Cloudflare）的 robots.txt 屏蔽 GPTBot、ClaudeBot、Google-Extended、Baiduspider 等 30 多个（2026-11-09 curl 核实）；推测是 Cloudflare 托管 robots.txt 自动生成。承泓上线前检查 Cloudflare 的 AI 爬虫 / 托管 robots 设置，别让 GEO 目标被默认值掐掉。2026-11-09 读官方文档：托管 robots 只在打开 Enable Bot Preference Sync 且有策略设 Block 时才往 robots.txt 前加屏蔽，文档没写新域名默认状态，所以每次上线实查（06 V6）。
- Awwwards 式重站伤 GEO：巡航永恒拆的 11 站首访 18–53 MB、6 站没处理减少动态、有的把字画进 WebGL（见 `20-项目记忆\其他\巡航永恒\参考拆解\README.md`）。主站要被搜索和 AI 引用，借手法前先判断可抓取性和重量。

## 规避策略
- 别信「npm misans = 官方切片」：2026-11-09 查 npm 发布者是 DSRKafuu，官方包只有整字库。用第三方字体包前先查 npm view 的 author / repository。
- 内置浏览器预览面板在后台时 requestAnimationFrame、IntersectionObserver、CSS 过渡都不跑（11-09 样板实测），动画类问题用 `tools/capture.mjs` 无头 Edge 验，页面里给动画加超时兜底回终态。
- SVG 的 fill / stroke 属性写 `var(--x)` 在 Chromium 不生效，经线不显示（11-09）：改写成 style="stroke:var(--x)"。
- WebSearch 是美国区通用引擎：中文词（「面料外贸独立站」等）首页被镜像垃圾页污染，国内官网（知衣、询盘云、微盟、POP）多抓不到（2026-11-09）。中文搜索意图结论只算推测，定稿前 Joe 在百度 / 小红书 / 豆包 / DeepSeek 复搜截图。
- 并行跑多个 `capture.mjs`：早期用随机调试端口，2026-11-08 撞端口抓成了别的站；已改成系统分配空闲端口，probe 里记 `finalUrl`，拆解前先核对它。
- `capture.mjs` 早期收尾只 `edge.kill()` 主进程，子进程残留，2026-11-09 攒到 267 个 msedge；已改 `taskkill /T /F` 杀整棵树（项目仓 `4a0da98`）。中途停子代理后，按命令行含 `cap-<端口>` 查残留并结束。
- 家用机无头 Edge 会带上账号同步和扩展（Tampermonkey、Sider、有道），抢焦点卡死截图、混进约 3.7 MB 扩展请求；body 不滚的站（Igloo、Lusion、Messenger）页高 = 一屏，脚本第 2 帧就停；软件渲染重 WebGL 截图会卡死。2026-11-09 项目仓 `5b9e264` 已修（`--disable-extensions --disable-sync`、`Page.bringToFront`、CDP 调用 45 秒超时、一屏高站照样按帧滚）。仍未覆盖：等加载器消失（Lusion 要等 `#preloader` 隐藏）、点击后再截（Messenger 要点 BEGIN），遇到时按站补脚本。
- 并行子代理共用会话 scratchpad，同名临时脚本会互相覆盖（11-09 Lusion 跑错一轮）：派子代理时给每站独立临时目录。
- 无头 Edge 截图里 WebGL / 地球 / 动画面板常是空白（Cloudflare、Stripe、Modal 都遇到）：这类主角时刻用内置浏览器补截或读源码，不凭空白截图下结论。
