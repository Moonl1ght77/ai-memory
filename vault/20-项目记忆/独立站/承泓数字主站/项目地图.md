## 技术栈
Joe 2026-11-09 确认：Astro 纯静态 + Cloudflare Workers 静态资源（不用 Pages、无适配器；Astro 官方部署页称 Cloudflare 推荐新项目用 Workers；静态资源请求免费），询盘表单走同一 Worker 的 `/api/*`。最大变量是国内访问速度：上线前广州 / 上海 / 北京手机实测，不达标改国内云 + ICP 备案。详见项目 `docs\strategy\06-开发验收.md`。

## 长期原则
- 证据来源 = Joe 现有项目（yanxinna.com、inwelltex.com、TKTX、织花云试运营、荣居 staging、小程序等），Joe 2026-11-08 同意案例具名；每条证据编号并指向记忆文件或网址，说不清的标「待证」，禁止编造。
- 「印花工作台」在主站上指织花云（Joe 2026-11-08 定），不是印花图案自动化工作台。
- API Token = 转售大模型 API（Joe 2026-11-08 定）。2026-11-08 核验：OpenAI / Anthropic / Gemini / MJ 条款都禁止转售或需审批，三家不服务中国大陆，境内还需备案 / 登记（项目 `docs\strategy\00-API转售合规核验.md`）。**Joe 同日定：API Token 先搁置待定**，主站策略和文案暂不写这条线。
- 主站页面上的主张、数字、客户名只用 `docs\strategy\04-主张证据矩阵.md` 里「可上」的；证据编号查 `00-证据底账.md`，每次发布前重跑其中 curl 项。易踩：织花云 2140 件作品主要是内部测试，不是出图量；「正库 337 款」属旧印花工作台，不算织花云；GoodJob 201 表 / 344 接口是上游开源规模；TKTX 有利多卡因合规风险，不具名。
- 合作口径（Joe 2026-11-09 定）：承泓是小型工作室，主打品牌化定制、先沟通再报价；主站不公开价格和固定周期，「多少钱」只讲价格取决于什么；首屏不写「开发者本人负责」；英文名 Chenghong Digital；域名 / 账号归属暂缓不写。
- SEO / GEO / FDE（Joe 2026-11-09 要上站，Joe 从零起步）：SEO/GEO 作为每个独立站交付自带的基础讲，没有客户排名 / AI 引用前后对比前不开代运营服务页、不承诺排名；FDE 作为合作方式讲（进到客户飞书 / 微信 / 表格里把 AI 跑通，证据泽鑫飞书作图），中文页不用「FDE」缩写。英维尔 11-09 实测有 sitemap / hreflang、无 llms.txt 和首页 JSON-LD，只能算 SEO 基础。
- 开发就是 Joe 本人（粘贴需求里的「@独立站开发」）。
- 研习文档每条标「事实 / 推测」；资产的生成方式一律算推测。
- 全站唯一主角时刻 =「面料拆成经线」（Joe 2026-11-09 定）：首屏面料纹理，滚到能力段拆成几根经线，每根对应一条业务线；SVG / CSS、零 WebGL、≤1.2s、减少动态给终态。全站视觉单位 = 经纬线 / 织纹。依据 `research\awwwards\00-汇总方法论.md`。
