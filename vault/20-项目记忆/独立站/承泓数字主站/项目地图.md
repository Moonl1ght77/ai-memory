- 证据来源 = Joe 现有项目（yanxinna.com、inwelltex.com、TKTX、织花云试运营、荣居 staging、小程序等），Joe 2026-11-08 同意案例具名；每条证据编号并指向记忆文件或网址，说不清的标「待证」，禁止编造。

- API Token = 转售大模型 API（Joe 2026-11-08 定）。2026-11-08 核验：OpenAI / Anthropic / Gemini / MJ 条款都禁止转售或需审批，三家不服务中国大陆，境内还需备案 / 登记（项目 `docs\strategy\00-API转售合规核验.md`）。**Joe 同日定：API Token 先搁置待定**，主站策略和文案暂不写这条线。
- 开发就是 Joe 本人（粘贴需求里的「@独立站开发」）。
- 研习文档每条标「事实 / 推测」；资产的生成方式一律算推测。
- 全站唯一主角时刻 =「面料拆成经线」（Joe 2026-11-09 定）：首屏面料纹理，滚到能力段拆成几根经线，每根对应一条业务线；SVG / CSS、零 WebGL、≤1.2s、减少动态给终态。全站视觉单位 = 经纬线 / 织纹。依据 `research\awwwards\00-汇总方法论.md`。
- 中文字体 = MiSans（Joe 2026-11-09 定）。官方 FAQ（hyperos.mi.com/font/zh/faq，2026-11-09 读）：免费商用、可嵌入，须注明使用了 MiSans（放页脚 / 关于页）；不得单独改字形外观。只有黑体，宣言对比用字重 + 品牌辅色；网页用官方 unicode-range 切片，取 2–3 个字重。西文数字 / 等宽用开源（Inter / Geist Mono）。完整许可协议未读，上线前核子集 / 再分发条款。
