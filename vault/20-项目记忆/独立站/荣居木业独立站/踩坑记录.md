# 荣居木业独立站 · 踩坑记录

> 最后更新：2026-10-27

- **npm script 调 Blender（路径带空格）**：Windows 下 npm 走 cmd，怎么转义都报 `'C:\Program' 不是内部或外部命令`。改用 `scripts/blender/run.mjs`（spawnSync，`BLENDER` 环境变量可覆盖路径）。
- **Poly Haven 木皮贴图方向不一**：oak_veneer_01 纹理竖向，walnut/ash 横向；旋转图片时法线贴图要同步换通道（CCW 90°：R'=255-G, G'=R），已写在 `prep_textures.py`。
- **american_walnut_veneer 是未上漆灰调**，不适合 Warm Walnut，改用 black_walnut_veneer_02 再调色。
- **Blender glTF 导出带法线贴图要 `export_tangents=True`**，否则 validator 报 MESH_PRIMITIVE_GENERATED_TANGENT_SPACE。
- **glTF Transform optimize 默认会 flatten/join**，会破坏 `*_TARGET` 节点，必须关 `--flatten/--join/--instance/--simplify`。
- **后台会话 worktree 隔离**：仓库无提交时无法建 worktree，先在 main 提交规范文档再 EnterWorktree。
- **Blender glTF 导出相机 yfov 用当前渲染分辨率算**：之前渲染过 512×256 探针，导出 yfov 按 2:1 算，浏览器画面被放大。导出前重设 1920×1080。
- **Blender 导出顶点色要指名**：`export_vertex_color="NAME"` + `export_vertex_color_name="AO"`；ACTIVE 模式导出全白。bmesh 要用 `float_color` 层（线性），byte 色会按 sRGB 解释。
- **three r186 已移除 PCFSoftShadowMap**（自动降为 PCFShadowMap 并警告）；`webglcontextlost` 监听不能 passive，否则 preventDefault 报错。
- **Nuxt `.client.vue` 组件 onMounted 时模板还没渲染**：ref 为 undefined，异常冒泡成整页 500。先 `await nextTick()`，并把启动包进 try，失败回海报。
- **Vue 批量 watch 会丢掉同一 tick 内的镜头往返**（selectPart→resetView），isTransitioning 卡死；渲染器要用 `flush: 'sync'` 逐事件驱动（27 组合矩阵测出）。
- **TypeScript 7 是 Go 版无 JS API**，vue-tsc 不能用，锁 `typescript@6`。Node 24.14 低于 Nuxt 4.6.3 声明的 ^24.15（目前能跑）。
- **Turnstile 测试 secret（1x…AA）对任意伪造 token 都返回 success**：只能验证接线，不能当防护；生产必须用真 widget。
- **请求自带 `cf-connecting-ip` 头打到 Cloudflare 边缘直接 403**：本地测试才加该头。
- **Workers 静态资源默认 auto-trailing-slash**：预渲染的 `/solutions/index.html` 会 307 到 `/solutions/`，配 `html_handling: drop-trailing-slash`。
- **代理环境下 Node fetch 不走 HTTP(S)_PROXY**（curl/wrangler 会），远程测试加 `NODE_USE_ENV_PROXY=1`。
- **three Reflector 只按本地 XY 平面（法线 +Z）镜像**：glTF 地面先 applyMatrix4(matrixWorld) 再 rotateX(π/2)，对象 rotation.x=-π/2。
- **顶点 AO 在只有角点的大面上会被插值抹开**：3 m 高板条正面角点贴地/顶棚，整面变暗导致换材质像素区分度掉到 11；AO 遮挡体只取木作+五金。
