## 已确认问题
- 2026-10-26 Project 云端线程的网络读不了：竞品官网的浏览器渲染页（Naadam / Sunspel 价格表、Icebreaker 全站、On 筛选与详情页）、Trustpilot、Reddit、Meta 广告库、TikTok Creative Center、Google Trends，也不能截图。能读：静态网页文字、SmartCustomer（原 Sitejabber）、户外论坛、HN Algolia API。需要浏览器的调研放本地线程做。云端线程也不能在本机跑 git pull。

- 2026-11-02 agent-reach 不支持抖音；分享页 SSR 不带视频数据。可行：内置浏览器打开 douyin.com/video/<id>，脚本把 video 元素挪到全屏、逐秒 seek + 截图读帧（登录弹窗挡画面，挪 video 就绕开）。拿不到口播音频。
- 2026-11-02 artifact 页面 CSP 只放行 CDN 的脚本，fetch/wasm 一律拦：three.js DRACOLoader 的解码器（wasm + wrapper js）必须作为附属文件和页面一起发布，`setDecoderPath('draco/')`。meshopt 同体积大 4.5 倍（2.65 MB vs Draco 0.58 MB），不选。
- 2026-11-02 artifact 附属文件只收常见网页类型，.glb 直接被拒（model/gltf-binary 不在名单）：改成 base64 的 `.glb.txt`（0.58 MB → 0.77 MB），页面 fetch 文本后 atob 再 `GLTFLoader.parse`。scratchpad 里的二进制文件发布会被读权限拦，复制到会话目录（`.claude/tryon-pub/`，不入库）再发。
- 2026-11-02 针织贴图尺寸：UV 以米为单位时，平铺块越小针脚越细——第一次把 Knitted Fleece 设成 0.15 m，一针约 1.5 mm，Hero 里完全看不见，要约 4 mm 一针（0.25–0.45 m）才读得出；Poly Haven 自带法线在网页尺寸下太弱，用照片明暗高通后当高度再叠一层法线。袖子沿用躯干的圆柱 UV 会拉伸成条纹和旋涡，袖子要按上臂、前臂两段骨单独展开，接缝放腋下。暗色衣服（Ink）的 sheen 颜色不能往白色偏，否则整件发灰。
- 2026-11-02 Blender 衣服生成：短袖用无限平面切会把躯干侧面一起切掉（A 字臂斜着，平面扫过腰侧），要只删 |x| 在袖子一侧的面；领口用平面切会切掉肩线，要用斜椭圆圈；按骨骼权重选面得到锯齿下摆，改平面切。MPFB 默认带辅助几何（眼球、关节方块），导出前按 HelperGeometry / JointCubes 顶点组删掉。

## 待二次验证的做法：参考驱动的可交互原型（下个项目再验证一次有效就做成 skill）
- 流程手册：https://claude.ai/artifact/WgakGccdyEoWYr55Y44Pxg ；口令「参考原型」见日常口令。
- 来源：2026-11-02 家用机，Lorenzo 原型 v2 一天内做到 Joe 满意（https://claude.ai/artifact/AtdH7anEY3hnYch6d1tLam）。
- 流程：同步现状 → brief 对照已定事项列冲突、Joe 逐条拍板 → 收参考（参考站 / 配色图 / 字体图 / 效果图，各一张即可）→ 读参考站源码（脚本 + 样式）提取真实色值、字体、动效时长与缓动、结构 → 出一页视觉样板（色卡、字体对照、关键组件、动效演示）→ Joe 确认 → 做整站单文件网页 → 本地服务 + 脚本实测桌面 1440 / 手机 390 → Critic 打分 → 过了再给 Joe → Joe 给现象 + 参考图反馈 → 迭代，每轮决定写记忆。
- Joe 11-02 定的规则：
  1. 不管开头怎么说，默认先出样板、等 Joe 确认再做整站。
  2. brief 和 Builder / Critic / Loop 提示词由 Joe 在 Claude chat 生成后给链接；缺参考站 / 配色图 / 字体图时，Claude 自己上网找 3–5 个候选、读代码出对比页给 Joe 挑，选定后深读再做。只学手法，不碰对方 Logo、图片、文案。
  3. 要 Critic 打分（brief 第 10 节，≥ 85 且无 P0 / P1），过了再给 Joe 看。待定：Critic 用独立子代理（不带 Builder 上下文）以免自评偏宽。
  4. 交付先统一用 claude.ai 私有网页（单文件 HTML，同一网址迭代）。
  5. 动效手感 Claude 验不了，Joe 每轮回一句手感反馈。
- 这次的关键动作（写进 skill）：参考站动效靠读代码不靠截图（`scripts-*.js`、样式表、筛选脚本）；单文件页本地预览要另包 head（charset + viewport）；浏览器面板在后台时动画暂停、截图停首帧，用脚本查状态；转场 / 菜单 / 计数等动画回调都加超时兜底。
- 第二次使用（2026-11-02 3D 试穿 Hero，家用机）：参考是抖音视频，读法改成逐帧截图（没有源码可读）；先用 AskUserQuestion 对齐 3 个决定 + 1 个装插件授权，再做样板。Critic 用独立子代理（不带 Builder 上下文）有效：3 轮 68 → 85 → 90，抓到的问题本地自测都漏了（发布包装差异、减少动态效果路径、手机首屏看不到卡片、兜底关不掉卡片）。待 Joe 看样板后判断流程是否可定型。
- 和现有技能的分工待定：全局规则 14 默认界面设计 oil-ui-pro、前端 oil-frontend、同任务一个主流程；这套流程管"参考 → 原型"，做 skill 时写清与两者的分工。
