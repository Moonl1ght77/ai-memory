# Lorenzo · 项目地图

## 项目定位
给一个商家做外贸 DTC 独立站：海外消费者直接下单付款。品牌 Lorenzo，两条线：羊毛系列、运动系列。负责人 Joe。
- 品类范围（Joe 2026-10-26）：只做男装；首版只做上衣，其它品类暂时没有。
- 市场（Joe 2026-10-26）：欧美，Shopify Markets 分美国 / 英国 / 欧盟；首版只做英文。
- 商家信息规则（Joe 2026-10-26）：要问商家的一律按虚拟假设走。
- 品牌架构（Joe 2026-10-26）：主线卖运动，支线卖羊毛，支线不单独起名；同域名、页头切换两套菜单（参照 Margiela 结构，不学视觉和数字编号）。
- 验收（Joe 原话）：商家满意。建议改成三个签字点，待 Joe 确认（见立项三件套）。
- 失败（Joe 原话）：和奢侈品以及运动品的独立站雷同。
- 品牌调性（Joe 2026-10-26）：商家要和「老钱风」搭边。理解为借老钱的讲究和克制，不做奢侈品站（日光、露价、动作中的人、工厂实景；不用纹章 / 马球手 / 交织字母，不编历史年份），待 Joe 确认这个理解。
- 视觉方向（Joe 2026-11-02 改定）：方角；打折可划线原价；首屏 3 张英雄轮播。旧方向 D「会所与工坊」（`docs\阶段3-视觉.md`）和 3D 高尔夫球首屏作废。
  - 字体：Joe 11-02 定 **Courier Prime**（Google 免费等宽），全站使用；取代简报的 Oswald / Inter。
  - 配色（候选，待 Joe 看样板确认）：取 Joe 给的截图——橄榄褐 #5E5644 底 + 奶油 #EAD8C9 字，补纸白 #F4EDE4 主背景、墨橄榄 #2F2B22 正文、铁锈 #B4461F 运动线、燕麦 #C9B48F 羊毛线（只配墨橄榄字）、灰橄榄 #6E6656 小字；取代简报的海军蓝体系。对比度均 ≥ 4.5:1，不可用：橄榄字放燕麦底 3.6、奶油字放铁锈底 3.95。
  - 商品卡（Joe 11-02 要）：照参考站，图下「名称 [颜色]」+ 右侧价格；悬停图上左「(货号)」右「( VIEW PRODUCT )」整行跟鼠标上下走。
  - 视觉样板页（私有）：https://claude.ai/artifact/3UqFfb7oi7BiaWSrGCW1cy
- 参考站 oddritualgolf.com 技术（11-02 读其 `scripts-2026.js`）：Webflow 做、Udesly 转 Shopify；GSAP（Flip / Observer / ScrollTrigger / CustomEase）+ SplitType 逐行逐词 + Lenis 平滑滚动 + Barba + Lottie。手法：clip-path 上下“拉帘”切图（1s）+ 图内 10% 视差；菜单幕板依次落下（0.575s、错开 0.1s，expo）、悬停其余链接变淡；商品卡跟随鼠标的货号 / VIEW PRODUCT 行（y 跟随 0.4s power3）；商品带自动漂移、可拖拽；页脚商品列表悬停有跟随大图；进站加载约 2.5s（字标淡入 + 图拉帘 + 幕布收起）；进站弹 Klaviyo 社群订阅窗。实际色：白 / 黑 / #F4F4F4 + 电光蓝 #050FFF，字体 PP Neue Montreal + Instrument Serif。
- 3D 试穿 Hero（2026-11-02 起，先羊毛）：网页不做实时布料模拟。人台与衣服都在 Blender 里用同一人体 + 同一骨架预贴合，导出静态 GLB；网页只播「环绕 → 飞到预贴合位置」。人体来源 MPFB（CC0 输出，家用机 Blender 5.2 已装 MPFB 2.0.18）；BlenderMCP 素材库和 3D 生成器都没开，没花钱。样板只用 Blender 视口预览，没做离线渲染。
- 素材（Joe 2026-10-26）：Joe 会提供一条高尔夫相关短片，穿插制作流程画面。高尔夫作为 Sport 主线的一个场景（建议 Golf / Commute / Travel），不另起线。
- 参考：Maison Margiela 的主线 / 支线结构，On 的按场景选品思路。只学结构和思路，不学视觉。
