
## 核心功能
1. 首页：品牌介绍、产品展示、畅销产品
2. 商店：WordPress 动态产品、分类筛选、排序、搜索、loading/empty/API error
3. 产品详情：`/product/[slug]` 动态路由、图库、颜色、规格、参数、附件、询盘
4. SEO：五语 SEO Title/Description、canonical、Open Graph、缺失产品 404/noindex
5. 多语言：俄/美英/英英/法/德 5 locale，产品翻译由 WordPress 管理
6. CMS：商家角色可新增、编辑、删除、发布、下架产品，不拥有系统管理权限
7. 缓存：WordPress 保存/状态/分类变化后，以服务端密钥通知前端按 tag 刷新
8. Manufacturing Capabilities（OEM 及服务）页：`/pages/manufacturing-capabilities`（B2B，5 语言）

## 部署注意
- Headless 版本需要服务端渲染与缓存刷新，不能继续按纯静态导出理解。
- 环境变量：`WORDPRESS_API_URL`、`WORDPRESS_REVALIDATE_SECRET`（至少 32 位，仅服务端）、`NEXT_PUBLIC_SITE_URL`。
- WordPress 只暴露白名单只读产品 API；管理员密码、刷新密钥不能进入客户端或 Git。
- 迁移数据一律导入为草稿；五语字段补齐并经过 staging 验收后才人工发布。
- 生产切换前必须完成真实 PHP/WordPress、Webhook、CORS、WAF/限流、媒体和桌面/移动视觉验证，并保留 Pages 回滚版本。

## 关键组件
- `SiteHeader` - 导航栏（搜索、语言切换，无购物车）
- `ContactFab` - 悬浮联系框（询问、邮件、WhatsApp、微信、返回顶部）
- `SearchModal` - 通过同源 API 查询 WordPress 产品
- `LocaleRegionSwitcher` - 语言/国家切换（带国旗图标）
- `FactoryStrengths` - 工厂实力展示
- `ProductDetailClient` - 保留原产品详情视觉，交易区改为样品/询盘
