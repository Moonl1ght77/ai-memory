## 技术栈
- 框架：Next.js 15 (App Router) + TypeScript
- UI：React 19 + Tailwind CSS 3
- 动画：Framer Motion；图标：Lucide React
- 支付：Stripe Checkout
- 字体：Inter（正文）+ Oswald（展示）

## 目录结构
```
app/              # 页面路由
components/       # UI组件（home / layout / ui / shop / product / cart）
providers/        # Context Provider
hooks/            # 自定义 Hooks
lib/              # 工具函数
types/            # TypeScript 类型
public/           # 静态资源
```

## 核心功能
1. 首页：品牌介绍、产品展示、畅销产品
2. 商店：分类筛选、排序、产品列表
3. 产品详情：图片轮播、尺码选择、加入购物车
4. 购物车：本地存储、数量调整
5. 结账：PayPal 支付（统一 USD 结算；Stripe route 为 501 占位，静态导出下不部署）
6. 多语言：俄/美英/英英/法/德 5 locale；价格以 USD 为基准按静态汇率展示（lib/utils.ts usdDisplayRates）
7. 响应式：手机端适配
8. Applications OEM&ODM 产品目录页：/pages/applications（B2B，5 语言）

## 部署注意
- 静态导出（next.config output: "export"），无服务端 API，表单靠 mailto / PayPal 订单携带
- Cloudflare Pages 监听 feat/homepage-effects：**每次推 master 后必须同步强推该分支**
- NEXT_PUBLIC_PAYPAL_CLIENT_ID 需配置在 Cloudflare Pages 环境变量（构建期注入）；本地 .env.local 用沙箱值 "test"

## 关键组件
- `SiteHeader` - 导航栏（搜索、语言切换、购物车）
- `ContactFab` - 悬浮联系框（询问、邮件、WhatsApp、微信、返回顶部）
- `SearchModal` - 搜索弹窗
- `LocaleRegionSwitcher` - 语言/国家切换（带国旗图标）
- `FactoryStrengths` - 工厂实力展示

## Git 与分支
- `master`：开发分支
- `feat/homepage-effects`：生产分支（Cloudflare Pages 监听此分支）
- 分支命名：feat/xxx、fix/xxx、chore/xxx；Commit 用中文描述
- 完成任务后：手机端适配 + 推送 GitHub
