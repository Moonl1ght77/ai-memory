## 技术栈
- 框架：Next.js 15 (App Router) + TypeScript
- UI：React 19 + Tailwind CSS 3
- 动画：Framer Motion；图标：Lucide React
- 支付：Stripe Checkout
- 字体：Inter（正文）+ Oswald（展示）

## 目录结构
```
app/              # 页面路由
components/       # UI组件（home / layout / ui / shop / product / cart）
providers/        # Context Provider
hooks/            # 自定义 Hooks
lib/              # 工具函数
types/            # TypeScript 类型
public/           # 静态资源
```

## 核心功能
1. 首页：品牌介绍、产品展示、畅销产品
2. 商店：分类筛选、排序、产品列表
3. 产品详情：图片轮播、尺码选择、加入购物车
4. 购物车：本地存储、数量调整
5. 结账：Stripe 支付集成
6. 多语言：俄语/英语/法语/德语
7. 响应式：手机端适配

## 关键组件
- `SiteHeader` - 导航栏（搜索、语言切换、购物车）
- `ContactFab` - 悬浮联系框（询问、邮件、WhatsApp、微信、返回顶部）
- `SearchModal` - 搜索弹窗
- `LocaleRegionSwitcher` - 语言/国家切换（带国旗图标）
- `FactoryStrengths` - 工厂实力展示
