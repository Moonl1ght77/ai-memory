**缓存分三层（实测）**：
1. HTML 页面**无 CDN 缓存**：响应头 `Cache-Control: private, no-cache, no-store`，无 `cf-cache-status`。根因是 `app/product/[slug]/page.tsx` 用 `cookies()` 读地区 cookie，Next 判定动态渲染，全站 ƒ Dynamic（对应遗留 #1）。每请求跑一次 Worker。
2. 数据层**有缓存**：`lib/wordpress/client.ts` 的 `next: { revalidate: 300, tags }` 落在 KV，Worker 渲染不回源 WordPress；内容变更由 webhook 立即打掉（实测 8 秒生效）。
3. 静态资源走 Cloudflare assets，正常缓存。

**HTTPS 实测（回答"客户会不会红屏不安全"）**：不会。`isSecureContext: true`、0 个 http 子资源、无混合内容告警、`ssl_verify_result=0`、check-host 23 个海外节点 HTTPS 全 200。真·红屏只有证书错误才出（过期/域名不匹配/没配 HTTPS）；混合内容不红屏，是掉锁+图片被拦。

### 上线前置：HTTPS / SSL（2026-07-30 Joe 问过，尚未执行，以下为待办不是已验证结论）

成本 0 元，**买主机时不要加购阿里云的收费 SSL 服务**。两个面分开办：

1. **前端站**：域名接入 Cloudflare 后 Universal SSL 自动签发、自动续期，免费，无需操作。现在的 Pages 和未来的 Workers 都一样；staging 用的 `*.workers.dev` 本身就是 HTTPS。
2. **WordPress 主机**：阿里云轻量装完镜像默认只有 HTTP，要自己配。做法 = 源站装 Let's Encrypt（certbot / 宝塔一键，90 天自动续期）+ CMS 子域接进 Cloudflare 开代理，**加密模式必须设 Full (strict)**。
   - **坑**：加密模式留成 Flexible 时浏览器有绿锁，但 Cloudflare 回源那段是明文 HTTP = 假加密。Full (strict) 要求源站真装了证书。

为什么是硬要求，不是可选：
- 后台登录密码明文传输。
- `YANXINNA_FRONTEND_URL` 必须 HTTPS + 标准端口，否则 `wp_http_validate_url()` 拒绝，webhook 静默跳过（见 `docs/wordpress/deployment.md` 第 24 行，唯一痕迹是 PHP 日志一行 `Cache refresh skipped: invalid frontend URL.`）。
- 媒体 URL 跟 siteurl 走；siteurl 是 http 时 HTTPS 页面里全是 HTTP 图片 = 混合内容被浏览器拦，整站断图。2026-07-30 验收没暴露这条，是因为 cloudflared 隧道自带 HTTPS。

## 备忘（Joe 反复问过的概念）
- **主机 ≠ 域名**：主机是租的服务器空间（像租仓库），域名是网址（可后买，验收阶段用主机送的临时网址即可）。
- **「独立站的支付功能」（顾客付款，本站不做）和「买主机的付款」（交服务器租金）是两回事**，别混。
- **SSL 证书不用买**：前端 Cloudflare 免费自动给，WordPress 主机用免费 Let's Encrypt。详见上面「上线前置：HTTPS / SSL」。
- **Cloudflare 不是测试工具，是生产平台**。Joe 多次以为「Cloudflare 只是拿来测试/给商家看的」。事实：老生产站 `yanxinna-store.pages.dev` 就跑在 Cloudflare Pages 上已好几个月；`...-cms-staging.workers.dev` 叫 staging 只是**我们起的名字**，不是平台限制，改个名部署上去就是正式站。免费额度 10 万请求/天，本站远远用不到。且不构成锁定 —— 代码在自己的 GitHub，换 Vercel 或自建只改部署配置。
- **前端不能「放进 WordPress」**。这套是 Headless：WordPress 只是个带后台的数据库（存产品 + 给商家加产品），页面由 Next.js 渲染。要把前端放进 WordPress = 把整套 React 站重写成 PHP 主题，推倒重来，且速度还是要靠 CDN。**WordPress 是商家的进货口，Next.js 是客户的门面**，两个东西不是一个东西的两半。
- **域名只是指路牌，指哪都行**。同一个域名的不同子域可指向完全不同的地方（主域指 Cloudflare、`cms.` 指阿里云）。买了主机不等于所有东西都得放主机上。**速度只取决于代码在哪台机器上执行**，与域名指谁、买没买主机无关。
- **老生产站为什么还有购物车和价格**：它从 `feat/homepage-effects` 分支构建，那分支上 `app/cart/`、`app/checkout/`、`app/api/stripe/`、`paypal-provider.tsx` 等 12 个文件原封未动。删干净的是 CMS 分支，从没合并没部署。要给商家看新版就发 staging Worker 网址，不是 `pages.dev`。
