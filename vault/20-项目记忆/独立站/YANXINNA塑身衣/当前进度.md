### 安全加固（提交 `5c98c7b`）
- WordPress 默认三处泄露同一批用户名，全部实测坐实并一并 404：`/wp-json/wp/v2/users`（返回全部用户）、`/?author=N`（301 带出 slug）、`/author/{slug}/`（归档页 200）。只堵 REST 端点等于没堵。
- 实现：`rest_endpoints` 过滤器移除 `/wp/v2/users*`；`template_redirect` 优先级 1 拦作者归档（**必须早于 `redirect_canonical` 的默认 10**，否则先 301 出用户名）。
- 两处均放行已登录用户，实测未登录 0 条路由、管理员 6 条，后台区块编辑器不受影响。产品 API 未被误伤（200）。
