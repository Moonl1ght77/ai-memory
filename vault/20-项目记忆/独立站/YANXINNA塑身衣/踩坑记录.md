# YANXINNA塑身衣独立站 · 踩坑记录

## 已解决的问题

### 1. 微信二维码弹窗定位问题
- 问题：弹窗被父容器 `fixed right-0 top-1/2` 限制，无法居中显示
- 解决：将弹窗移到父容器外面，使用 Fragment 包裹
- 文件：`components/ui/contact-fab.tsx`

### 2. 微信弹窗手机端适配
- 问题：手机端弹窗居中显示，看不到二维码
- 解决：手机端改为从右侧滑出，占 85% 宽度
- 关键代码：
```tsx
<div className="fixed right-0 top-0 h-full w-[85vw] max-w-[340px] bg-white shadow-2xl sm:static sm:mx-auto sm:h-auto sm:w-[340px] sm:rounded-xl">
```

### 3. 语法错误导致构建失败
- 问题：Fragment 标签 `<>` 没有正确闭合，div 标签嵌套错误
- 解决：修复 div 标签的嵌套结构，确保正确闭合
- 教训：修改 JSX 结构时要仔细检查标签闭合

### 4. Cloudflare Pages 不同步
- 问题：提交到 master 分支后，Cloudflare Pages 没有自动部署
- 原因：Cloudflare Pages 配置为监听 `feat/homepage-effects` 分支
- 解决：将 feat/homepage-effects 分支重置为 master 内容
- 教训：生产分支和开发分支要保持同步

### 5. 国旗 emoji 在 select 元素中不显示
- 问题：原生 `<select>` 元素不支持显示 emoji 国旗图标
- 解决：改用自定义下拉菜单组件
- 文件：`components/layout/locale-region-switcher.tsx`

### 6. select 元素不支持图片
- 问题：用户希望显示真实国旗图片，但 select 元素不支持
- 解决：使用自定义下拉菜单 + next/image 组件显示 `/images/flags/*.png`

### 7. PayPal 不支持 RUB，且 SDK 货币必须与订单一致
- 问题：PayPalScriptProvider 写死 `currency: "USD"`，下单却用地区货币（RUB/EUR/GBP），非 USD 报 currency mismatch；PayPal 根本不收 RUB，俄罗斯主市场无法付款
- 解决：统一按 USD 结算（`currency_code: "USD"`），展示价格用静态汇率换算（`lib/utils.ts` 的 `usdDisplayRates`），结账页加"以 USD 结算"多语言提示
- 教训：跨境收款先查支付渠道支持的货币清单，展示货币≠结算货币

### 8. 生产分支落后复发（踩坑 #4 二次发生）
- 问题：2026-07-13 发现 origin/feat/homepage-effects 落后本地 master 63 个提交，线上一直是旧版（产品都是旧的）
- 解决：`git branch -f feat/homepage-effects master` + `git push --force-with-lease`
- 教训：**每次收工推送 master 后必须同步强推 feat/homepage-effects**，两个动作绑定执行

### 9. ip-api.com 免费版仅 HTTP
- 问题：HTTPS 站点发 HTTP 请求被浏览器 mixed content 拦截，IP 地区检测永远失败
- 解决：换 `https://ipwho.is/`（免费支持 HTTPS，字段 country_code/success）
- 文件：`lib/region.ts`

### 10. BorderGlow 光晕导致手机端横向溢出
- 问题：edge-light 用负 inset 超出卡片 40px，手机端页面出现 24px 横向滚动
- 解决：外层 section 加 `overflow-x-clip`（不裁 y、不产生滚动容器，光晕 hover 效果保留）
- 文件：`components/home/factory-strengths.tsx`

### 11. 西里尔文导航更长，断点要按最长语言测
- 问题：导航加到 6 项后，俄语标签在 1024-1280 宽度溢出（英语没问题）
- 解决：桌面导航断点 md→xl（1280 起显示），中屏走汉堡菜单；nav 加 whitespace-nowrap，字距收窄 0.2em→0.12em
- 教训：多语言站改导航/按钮布局，必须切到俄语（最长）验证

### 12. 静态导出（output: export）没有后端，表单收不到数据
- 问题：样品申请表单原来只 console.log，询盘全部丢失；结账地址表单也没有去向
- 解决：询盘表单改 mailto 直达业务邮箱；结账地址塞进 PayPal 订单 shipping（SET_PROVIDED_ADDRESS），在 PayPal 后台可见
- 教训：静态站表单只有三条路——mailto、第三方表单服务、塞进支付订单

## 待解决的问题
- Cloudflare Pages 的 NEXT_PUBLIC_PAYPAL_CLIENT_ID 是否已配置未确认（NEXT_PUBLIC_ 变量构建期注入，没配则线上结账显示 "PayPal Not Configured"）

## 经验总结
1. 弹窗组件：不要被父容器的定位限制，要用 Fragment 移到外面
2. 手机端适配：弹窗类组件要考虑从边缘滑出的交互方式
3. JSX 语法：修改结构后要仔细检查标签闭合
4. 部署分支：确保开发分支和生产分支同步
5. 自定义组件：原生 HTML 元素功能有限时，考虑自定义实现
6. 多语言同步：修改文案时要同步更新所有5种语言版本（ru-RU、en-US、en-GB、fr-FR、de-DE）
7. 图片路径：新图片放 `/public/images/` 目录，使用 next/image 组件加载
