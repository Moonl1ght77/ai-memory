# agent全自动生图 · 项目地图

Joe 最重要的项目之一：在 LumaX Flow 无限画布平台上构建「商用级服装一致性生图工作流（完全体）」——输入6张参考图+2张需求卡，全自动产出8分镜模特实拍风商用图+质检报告+详情页素材。目标：85%以上直接可商用。

## 技术栈
- 平台：LumaX Flow 无限画布，卡片类型 text/sticky_note/ai_chat/ai_image/ai_tryon 等
- 编排模型：gpt-5.5（provider jijing）；渲染模型：gpt-image-2（3:4/1K/high，可切 Gemini 3 系）
- 本地自动化接口（Automation Gateway）：`E:\LumaX Flow\data\agent\agent.json` 读 port+token，base=`http://127.0.0.1:{port}/agent/v1`；apply搭图免费幂等、run才计费；官方协议文档在 `E:\LumaX Flow\data\agent\`（AGENTS.md/graph-schema.json/docs/）
- 构建工具：Python 3.12（`py` 启动器）

## 核心架构（V9.1 定制版，35卡/109连）
输入6图+2需求卡 → S1场景清洗 → A1商品DNA(含版型硬指令)+A2模特DNA+A3场景八分镜 并行 → C总控编译器(8组英文正/负提示词) → P1-P8抽取器 → G1-G8生图(原生多图槽位锁) → QA八图质检(含版型专项) → R/RG返修支线 → X1四宫格+X2详情页。
V9.1 关键定制（按 Joe 实测反馈）：砍掉 S2A选品/S2B白底资产（AI不自主选品），IN6=用户直接给搭配单品白底图进槽4；八分镜按商家淘宝主图标准=前4版型标准位(正面全身/背面全身/正面近景/左45°)+后4同场景生活位；需求卡②「版型上身要求」为硬指令链路 REQ2→A1→C(Fit Execution Law)→QA(紧身出宽松=硬失败)。
6个运行组=商用检查点：①场景清洗②分析编译③生图④质检⑤返修⑥详情页。
生图卡槽位：槽1模特/槽2商品/槽3细节/槽4搭配单品(IN6)/槽5场景/(仅G5)槽6姿势。

## 长期原则
- **连线顺序=参考图槽位顺序**（平台硬规则），生图卡统一：槽1模特/槽2商品/槽3细节/槽4资产/槽5场景/(仅G1)槽6姿势；提示词前缀必须与连线序一致，乱动连线=一致性崩塌。
- 改提示词只改 blueprints/prompts/*.txt，改结构只改 workflow_spec.json，然后重跑构建器——禁止绕过蓝图直接改 .lxf 或画布后不回写。
- 平台引擎禁环；反馈回路一律做成"QA→R→RG 返修支线+单卡重跑"。
- run 会消耗 Joe 的余额，批量运行前必须先向 Joe 确认。
