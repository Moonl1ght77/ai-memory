## 核心架构（V9.2 定制版，37卡/113连）
输入8图+2需求卡 → S1场景清洗(干净图自动原样复刻) → A1商品DNA(版型硬指令+字段9背面结构)+A2模特DNA+A3场景八分镜 并行 → C总控编译器(8组英文正/负提示词) → P1-P8抽取器 → G1-G8生图(原生多图槽位锁) → QA八图质检(版型+机位专项) → R/RG返修支线 → X1四宫格+X2详情页。
V9.2 关键精修（按素材C两组品牌参考图，2026-07-08）：①版型默认值=品牌实际「修身运动版(贴合非压缩)」，A1/C/QA三态版型口径(修身/压缩/宽松)全链路对齐；②机位统一铁律=8分镜全部固定正面平视只允许人物姿势变化，G4由左45°改为正面下摆互动位，QA硬失败13=机位违规；③IN7背面商品图定向路由(A1+G2槽6+QA，其余生图卡不可见——防参考图过载幻觉)；④IN8版型上身参考仅连A1(防人物身份污染)。
V9.1 遗留定制仍有效：AI不自主选品，IN6=搭配单品白底图直进槽4；硬指令链路 REQ2→A1→C(Fit Execution Law)→QA。
6个运行组=商用检查点：①场景清洗②分析编译③生图④质检⑤返修⑥详情页。
生图卡槽位：槽1模特/槽2商品/槽3细节/槽4搭配单品(IN6)/槽5场景/(仅G2)槽6背面商品(IN7)/(仅G5)槽6姿势(IN5)。
素材C：`素材C\作图自己的品牌参考图（版型确定）\`(7张，版型标准+IN8素材) + `素材C\参考品牌（构图+姿势）\`(12张，正拍机位语法来源)，已随仓库同步。

## 长期原则
- **连线顺序=参考图槽位顺序**（平台硬规则），生图卡统一：槽1模特/槽2商品/槽3细节/槽4资产/槽5场景/(仅G1)槽6姿势；提示词前缀必须与连线序一致，乱动连线=一致性崩塌。
- 改提示词只改 blueprints/prompts/*.txt，改结构只改 workflow_spec.json，然后重跑构建器——禁止绕过蓝图直接改 .lxf 或画布后不回写。
- 平台引擎禁环；反馈回路一律做成"QA→R→RG 返修支线+单卡重跑"。
- run 会消耗 Joe 的余额，批量运行前必须先向 Joe 确认。
