# YANXINNA 塑身衣独立站 踩坑记录

## 已解决的问题

### 1. 微信二维码弹窗定位问题
**问题描述**：弹窗被父容器 `fixed right-0 top-1/2` 限制，无法居中显示
**解决方案**：将弹窗移到父容器外面，使用 Fragment 包裹
**文件**：`components/ui/contact-fab.tsx`

### 2. 微信弹窗手机端适配
**问题描述**：手机端弹窗居中显示，看不到二维码
**解决方案**：手机端改为从右侧滑出，占 85% 宽度
**关键代码**：
```tsx
<div className="fixed right-0 top-0 h-full w-[85vw] max-w-[340px] bg-white shadow-2xl sm:static sm:mx-auto sm:h-auto sm:w-[340px] sm:rounded-xl">
```

### 3. 语法错误导致构建失败
**问题描述**：Fragment 标签 `<>` 没有正确闭合，div 标签嵌套错误
**解决方案**：修复 div 标签的嵌套结构，确保正确闭合
**教训**：修改 JSX 结构时要仔细检查标签闭合

### 4. Cloudflare Pages 不同步
**问题描述**：提交到 master 分支后，Cloudflare Pages 没有自动部署
**原因**：Cloudflare Pages 配置为监听 `feat/homepage-effects` 分支
**解决方案**：将 feat/homepage-effects 分支重置为 master 内容
**教训**：生产分支和开发分支要保持同步

### 5. 国旗 emoji 在 select 元素中不显示
**问题描述**：原生 `<select>` 元素不支持显示 emoji 国旗图标
**解决方案**：改用自定义下拉菜单组件
**文件**：`components/layout/locale-region-switcher.tsx`

### 6. select 元素不支持图片
**问题描述**：用户希望显示真实国旗图片，但 select 元素不支持
**解决方案**：使用自定义下拉菜单 + Image 组件显示 PNG 国旗图片
**关键代码**：使用 next/image 组件加载 `/images/flags/*.png`

## 经验总结
1. **弹窗组件**：不要被父容器的定位限制，要用 Fragment 移到外面
2. **手机端适配**：弹窗类组件要考虑从边缘滑出的交互方式
3. **JSX 语法**：修改结构后要仔细检查标签闭合
4. **部署分支**：确保开发分支和生产分支同步
5. **自定义组件**：原生 HTML 元素功能有限时，考虑自定义实现
6. **多语言同步**：修改文案时要同步更新所有5种语言版本（ru-RU、en-US、en-GB、fr-FR、de-DE）
7. **图片路径**：新图片要放到 `/public/images/` 目录下，使用 next/image 组件加载
