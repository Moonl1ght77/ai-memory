## 规避策略
- 选片台样板（2026-11-05）三个坑：① 压缩体片名按宽度放大 1.5 倍后两行会顶出舞台，字号要再按高度封顶：`min(按宽度算的字号, 33cqh / 行高)`；② 车压在片名上时，片名下面的中文小字会被车挡住，中文名改放片名上方；③ 松手时算甩的速度，要先看停手了多久，停手超过 80ms 再松开按 0 算，不然慢拖也会被当成甩。
- 实拍车图（2026-11-05）：① 原厂哈雷油箱几乎都带厂标（Bar & Shield、翼标、圆标、车型字），「找没 logo 的」基本找不到，要么选改装车，要么修图去标（CC BY-SA 允许修改，致谢里写明）；② Openverse 搜得到 Flickr 但缩略图常 424 失败，Commons API 更稳，缩略图只给标准宽度（330 / 960 / 1920，改网址里的 `NNNpx-`）；③ `pip install "rembg[cpu]"` 不带 OpenCV，修图要另装 `opencv-python-headless`；④ rembg 会把背后的墙上铁件、竖杆一起抠进来，要按坐标或「低透明度像素」再清一遍；⑤ Artifact 发布时用 `files` 带外挂图片被读权限规则挡住，改成 data URI 内嵌（21 张 WebP，页面约 1.3 MB）。
- 找好看的车照（2026-11-05）：① Unsplash 有防机器人验证、robots.txt 点名 Claude 系爬虫，Pexels 直接 403，按规矩不绕：好看的图请 Joe 自己搜到后发链接，我只查许可和处理；② Openverse 时好时坏（500、creator 参数被忽略），Flickr 大图从照片的 sizes 页取 `_k`（2048）地址；③ HDR 照片里镀铬会反出青绿色，加饱和会更怪，只压青绿色相（HSV 80–150）的饱和度；④ `grade.py` 会原地覆盖，重调色前要先重出没调过的抠图，否则会调两遍。
- 照片发糊（2026-11-05）：① 元素静止时也挂着 `perspective()` / `rotate()` 和小数像素 `translate`，再加 `will-change: transform`，浏览器按合成层重采样，照片明显变软；静止时改成整像素 2D `translate`，动的时候才加 3D；② 照片至少按 2 倍屏出图（舞台车宽约 800px，图要约 1600–2000px），用原图而不是 1024 / 2048 的中图；③ 按色相硬切压饱和会在暗色渐变上压出色块，别这么做；④ 查清晰度用 Playwright `deviceScaleFactor: 2` 截同一块区域对比。
- 参考站截图（2026-11-04 家用机验证）：本机无 Playwright，用 Edge 无头截首屏：`msedge --headless=new --user-data-dir=<临时目录> --window-size=1440,900 --virtual-time-budget=10000 --screenshot=<路径> <网址>`。不加独立 `--user-data-dir` 时连跑几次后不出图；加 `--use-angle=swiftshader` 会段错误；WebGL 站（lusion.co、vredestein-newhorizons.com）首帧是空的，要用内置浏览器看。Edge 无头最小窗口约 492 宽，`--window-size=390` 截出来右边被裁不代表页面溢出，要用脚本量 `scrollWidth`。
