## Joe 已拍板的决策（别再重复问）

- **集成中心不启用**（2026-08-23 定）。启用硬前提是 Redis + 独立 integration-worker 进程 + INTEGRATION_CREDENTIAL_KEY，控制面本身不要域名；但 Microsoft 365 / Google Workspace / Google Drive 三个连接器的 OAuth 回调**代码硬校验必须 HTTPS**，纯 IP 演示机连不上。6 个连接器里纯 IP 真能连通的只有 EasyPost（要 API Key，纯出站）和企业微信（同步出站可行、回执要公网回调）。**理由**：① 2C2G 只剩约 540MB 可用内存，当天刚 OOM 死机一次，再加 Redis+worker 风险高，演示当场崩比少个模块糟 ② 开了是"看得见连不上"，反而露短；现在显示"集成服务未启用"更好讲成"上线时按你们的邮箱/ERP 开通" ③ 集成中心不是成交点。**改主意的条件**：商家访谈明确提"必须打通 Outlook/企业微信"→ 那是刚需，直接上域名+HTTPS+注册 OAuth 应用，作为定制条款报价，不走中间态
- **服务器 admin 密码维持 goodjob123 不改**（2026-08-23 Joe 明确决定，AI 已提示过公网暴露风险）。演示机公网 8.217.160.84 任何人可登。**交付商家前必改**（项目地图"交付前必做"已列）
