# 小红书热点资讯数据流 · 踩坑记录

## 已确认问题
- **wow-trend 收费层必须走桌面客户端+机器授权，网页看不了**（2026-08-18 实测）：用 Joe 的 Chrome（opencli browser 桥）打开收费文章和 T台秀场页，全部 403，提示「未通过客户端登录…联系资讯顾问进行机器授权」。网页登录态解决不了。全盘扫描（C/D/E、注册表、开始菜单、进程）**这台电脑没装 wow-trend 客户端**。网页端只能看到栏目结构、文章标题、封面图。
- **wow-trend 文章正文未登录 403**（2026-08-18 实测）：`r.jina.ai` 只能读到首页结构和文章骨架，正文是收费内容。
- **opencli xiaohongshu note 抓不到笔记正文**（2026-08-18）：报 `xiaohongshu note now requires a full signed URL`，带 xsec_token 的完整 URL（profile 形式和 explore 形式都试过）仍报 `Navigation rejected`。`user` 命令列笔记正常。本项目不依赖抓正文，暂不修；以后要抓再排查（2026-10-12 CLI 已升 1.8.8，未重测）。
- **OpenCLI 扩展从公司机 Chrome 消失**（2026-10-12）：`opencli doctor` 报 `Extension: not connected`，`opencli daemon restart` 后等 30 秒仍不握手。查 Chrome 三个 profile 和 Edge 的扩展列表，都没有 OpenCLI（其他扩展都在）；原因未查明（假设：被浏览器移除或被手动删）。商店页仍在（GitHub 最新 v1.8.8，扩展 1.0.24）。对策：开工先跑 `opencli doctor`，Extension 显示 MISSING 就让 Joe 从商店重装；CLI 已同步升到 1.8.8。
- **网页端每篇只放 4 张真图，其余是收费占位图**（2026-10-12 实测）：get-article-res 里所有资源 `is_power:false`，60 个资源里 56 个指向同一张「收费内容，无权限查看」占位图；发布会、订货会、品牌报告都一样。08-18 记的「看图不受限」不对，001 只有 4 张内页图就是这个原因。要完整图集只能走桌面客户端加机器授权，或找 wow-trend 业务（WOWTREND001 微信）问清订阅范围。**不要拿桌面客户端的 token 去绕网页收费层**：属于绕访问控制，还可能触发单点登录风控连累账号。代码里按「同一链接出现超过 2 次＝占位图」过滤（`src/parse.mjs`）
- **发布会 / 订货会没有文字**（2026-10-12）：description 为空，get-page-list 返回空，每张图的标签只有品牌、季节、城市；拆知识点只能看图。报告正文在每页的 title / description / html，sketchpad_info 里的 `name` 是设计稿图层名，不能当正文收
- **打印 wow-trend 的 localStorage 键名会泄露 token**（2026-10-12）：网站拿 `Bearer<JWT>-72105` 当缓存键名。排查只打印过滤掉 `Bearer` 开头的键名；值一律不打印（里面还存着账号密码）
- **天亿马上各模型的坑**（2026-10-12）：claude-sonnet-5 不支持 `response_format: json_object`（返回 400）；gemini-3.8-flash 支持，但输出里一半是推理 token；gpt-4.1-mini 看图便宜（600 宽一张约 300 token）
- **别用 PowerShell `ConvertFrom-Json` 读 Chrome 的 `Local State`**（2026-10-12）：解析失败时，报错会把整段原文（含各 profile 的账号信息和加密键）打出来。查扩展改用 node 只取 `extensions.settings` 里需要的字段。

## 风险
- **wow-trend 图片版权**：订阅只是使用权，图片著作权在 WOW-TREND/原摄影方。公开搬到小红书可能被投诉或单篇下架。2026-08-18 已向 Joe 说明，Joe 知情决定混用（卡片+wow-trend 图）。若被投诉，回退方案是全卡片化。
- **wow-trend 账号单机绑定**：换电脑/重装系统会丢登录态，流水线绑死这台机。
- **秀场真图带 WOW TREND 水印**（2026-10-12 实测）：右下角有 logo，不去水印是底线，所以发出去的图等于公开标明出处，被 wow-trend 注意到的概率更高
- **色卡和趋势报告比秀场图更敏感**（2026-10-12 判断）：它们是 wow-trend 自己卖的产品，原样搬发容易被认出，可能被投诉下架，最坏连订阅账号受影响（推测）。对策：色卡从秀场图自己取色做，文字自己写，不截报告页、不去水印。
- **小红书平台功能网上说法冲突**（2026-10-12 查）：定时发布（「最多提前 7 天」vs「个人号没有」）、私信关键词自动回复（「已下线」vs「专业号有，或需每月广告消耗 ≥1000」）。以单品账号后台实际看到的为准，不按网文设计。
- **小红书抓数据会被风控**（引自获客系统 2026-08 实测）：新号 6 分钟被断，老号 18 分钟没事。抓数用抓数号，绝不用单品的发帖号。

## 规避策略
- 抓 wow-trend 一律走本机浏览器会话，不导 Cookie 到别处，不多端登录（怕触发风控踢下线）。
