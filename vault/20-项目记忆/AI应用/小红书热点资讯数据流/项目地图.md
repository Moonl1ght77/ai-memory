## 料源与工具
- **wow-trend.com**：Joe 付费账号（钻石VIP，企业=广州单品纺织·针织面料）。**单点登录**（别处一登这边掉线），登录态在本机 Chrome。抓料走 opencli browser 桥借 Chrome 会话。
- **wow-trend 数据通道（2026-08-18 打通，全 API 化）**：
  - 认证：页内 localStorage `wowLoginToken`（JWT，约 2.5 天过期，Joe 正常用浏览器会自动续），请求头 `Authorization: Bearer <token>`
  - 订阅列表：`apps02.wow-trend.com/api/trend/subscrption/index?gender_id=72105&limit=N&page=N`（订阅池 3449 篇，含 article_id/标题/日期/封面/标签：品牌·季节·风格·地区）
  - 文章元数据：`apps03…/api/trend/article/get-detail?article_id=X&gender_id=72105`
  - 文章整页内容：`apps04…/api/trend/article/get-page-list?article_id=X&gender_id=72105&nav_id=15&menu_id=82827`（每页 sketchpad_info：图片 hd_url/preview_url + 文本块，结构化）
  - 图片 CDN `imgXX.wow-find.com` 公开可直接 curl 下载。**尺寸后缀 `!wrN` = N×100 像素宽**：接口默认给 `!wr5`（500 宽，糊），**改拼 `!wr12` 得 1200×1800（本账号上限）**；无后缀=1000 宽；wr15/wr20+ 无效或回落。报告页素材另有 `!composition`（约 2000 宽）
  - 订阅包范围：品牌深度报告/发布会/订货会（Balenciaga、CHANEL、Dior、Burberry、Gucci、Chloé 等）；色彩企划等栏目**不在包内**（403 是未订购不是没登录）；`is_download:false`=无官方打包下载权，但看图不受限
