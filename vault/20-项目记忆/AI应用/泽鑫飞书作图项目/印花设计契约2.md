# 印花设计能力 · 提示词契约（契约2）v2

> v1 定稿 2026-08-13；v2 同步 2026-08-19（提示词从"整句模板"改为"六槽位JSON+代码拼装"，模式清单补齐至9个）。
> 铁律：本契约内容焊在服务代码里，改契约=改代码重新部署；飞书聊天永远改不动它。

## 背景事实
- 客户泽鑫（睡衣品类）自己不知道要什么风格 → 流程必须"先给方向再出图"
- 客户要求可筛选：一次多风格、批量出（Joe 2026-08-13）
- 客户看图选号的场景，"所见即所得"是硬语义：出给他看的每张候选图都落盘留底，选中后从那张图出发加工，不从描述文字重来（2026-08-18 商家实弹定）

## 提示词架构（2026-08-19 Joe 拍板：全面规范化）
- **LLM 只填槽，不写整句**。花型生图提示词 = 六槽位 JSON：`style / motifs / colors / scale / density / background`
- **句式骨架代码拼装**（`_compose_prompt`）：seamless 前缀 + 六槽位定序拼接 + 铁律尾板
- **出口收口**（`_finalize_prompt`）：seamless / no text / no watermark / no human / IP防线 / 动物纹锚点——缺什么程序补什么，模板从"声明"变"保证"。LLM 没回槽位（裸文本/解析失败）退回裸文本收口，链路不断
- 成衣提示词走独立收口 `_finalize_mockup`（平铺铁律+无人无字+IP防线），不过 seamless 前缀
- **调度上下文**：state 存最近3轮"原话→判成什么模式"，只拼进调度器提问；**绝不进生图提示词**——图长什么样只跟最新一句走（Joe 2026-08-18 定）

## 模式清单（9个，调度器判决）
| 模式 | 触发 | 要点 |
|---|---|---|
| propose 出方向 | 要新款/没明确需求/"来一批X" | 8方向=2张四宫格并行（全局编号1-8）；宫格落盘留底；"来一批"句式焊死 propose 防低温抖动；纯换批话术继承上批偏好 |
| render 出效果图 | 回编号"要N" | **切宫格N号格子 img2img 忠实精绘放大**（同元素同构图同配色同尺度）；多编号一编号一张、3路并行上限3；宫格丢了退文字路线 |
| recolor 程序换色 | "N号换M个配色"/带图要配色 | **v3 分色映射**：原图聚主色簇→每簇映射调色板一色→多色并存；置换式染底（V不动保纹理）、LLM禁近白底色；上限5色版；纯程序秒级零费用 |
| revise 改图 | "底色深一点"等微调 | 拿上一版留底提示词让 LLM 只改点名部分 |
| mockup 成衣效果图 | "这个花型做成家居服" | 定稿印花当参考图（image 参数实测真吃图）；完全摊开无堆叠；单件款禁凑裤子；版型不锁：不点名=AI自由设计，点名照做（含时装品类直译）；产物不进 last_renders |
| vectorize 转矢量 | "转矢量N" | 多编号串行排队；锁+pgrep判活防重复开工；PDF>28MB走下载链接；超时转"后台续跑+取件" |
| bigtile 大回位 | "出64cm大回位" | 识别cm数/平接半步接/风格；5-8分钟后"大回位取件" |
| clarify 先确认 | 模糊话（"来一批似懂非懂的"） | **宁问不猜**：给3个方向选项让客户用话回，不给编号选项；防猜错白烧费用 |
| unknown 兜底 | 没学会的新玩法 | 明说"还没学会已记档"+报能力菜单；原话双登记（UNMET_NEED日志+state._unmet近20条） |

## 编号与留底规矩（多次实弹坑换来的）
- 用户的编号世界=宫格方向号；服务器索引=留底序号。统一走 `_pick_render`：先认方向号、再认留底序号、对不上**明说指路，绝不猜**
- 留底文件名带时分秒戳，全局唯一（同日多批同名覆盖=状态无声腐坏，真凶级坑）
- "来一批"增量更新会话不清老图；带编号操作碰上老批次图明说指路
- mockup/vectorize/bigtile 三模式下用户当条消息带的图先落成当前留底再开工（防拿老留底顶掉）
- 凡带 selection/images 的模式：**回显报的和执行用的必须是同一份数据**（回显装懂已五连坑）

## 差异化规矩（2026-08-19 "来来回回就那几个"逼出）
- 宫格四格必须像四个设计师的活；方向差异化=画法/构图/母题（至少5种画法+3种构图，禁共用画法母题），不是只换颜色词
- 全局不许硬编码色彩氛围（"柔和粉彩"三处硬编码已拆）；客户点名色彩氛围照办
- 动物纹锚点死规则（豹纹必含 leopard rosettes with broken dark ring outlines），差异化只许动配色/密度/花位

## 行话规则（焊入提示词，持续补充）
- **花位**=图案尺度："大花位"→大图案大循环，"小花位"→小碎花小循环，没提→中等（2026-08-13 Joe 定）
- **密度**独立于花位：疏/极疏/密/满印四档，默认"适度留白不拥挤"（2026-08-14 商家嫌密逼出）
- **底色**：白底是默认值不是铁律，客户点名照翻（2026-08-14 白底铁律废除）
- 完整词典见项目仓库 `CONTEXT.md`

## 死规矩（代码强制）
1. 提示词模板只存在于代码，聊天不可改
2. 出图先自查（尺寸/格式/张数），不合格自动重做 1 次，再不合格明确回复"本次未达标"，不硬交
3. 产物命名：泽鑫-日期-模式-编号（效果图带时分秒戳防同日覆盖）
4. 无关请求直接回"本能力只处理印花设计"，不接活
5. 失败/超量/超范围全明说，绝不静默兜底
