# 印花设计能力 · Joe 操作手册

> v1.0 · 2026-08-13 · 配套服务：print_design（已上线，待飞书验收）

## 一、现状一句话

"印花设计"子agent已部署到你的服务器并挂上平台，服务器端测试全过。**只差你在飞书里实测验收**。

## 二、验收操作（照抄即可）

1. 打开有智能助手机器人的那个飞书群（之前测"打火机海报"的群）
2. 发送：
   ```
   /调用 print_design 来一批新方向
   ```
3. **等 2～4 分钟**（生图慢，属正常，别重发）。应收到：8 个方向的文字清单 + 2 张四宫格图（图1=方向1-4，图2=方向5-8）
4. 挑一个看着顺眼的，发送（例）：
   ```
   /调用 print_design 要3
   ```
5. 再等 2～4 分钟，应收到 1 张该方向的效果图，文件名形如"泽鑫-20260813-效果-1.png"

两步都收到图 = 验收通过，告诉我"过了"。任何一步不对：**截图发我**，我远程查日志。

## 三、日常操作口令表

所有指令都以 `/调用 print_design ` 开头（同事加别名后可简化）：

| 想干什么 | 后面接什么 | 得到什么 |
|---|---|---|
| 看新方向 | 来一批新方向 | 8方向文字+2张四宫格 |
| 换一批 | 再来一批 | 新的8个方向（自动避开上一批） |
| 选中出图 | 要3 / 要3和7 | 选中方向的效果图（最多2张） |
| 直接提需求 | 想要小雏菊配淡蓝底的碎花 | 按描述出效果图 |
| 带参考图 | 图片和文字一起发 | 视觉解析参考图风格后出方向（2026-08-13 已实测可用） |
| 出交厂文件 | 转矢量（多张时带编号：转矢量 2） | 矢量PDF+300DPI TIFF（10cm回位），约4分钟 |

- 无关的话（天气/闲聊）会被拒收，这是设计好的守门行为
- **每条回复第一行是〔识别：…〕**——机器人对你这句话的理解回执。发现识别错了直接截图报修，不用等出图
- "要3"里的编号指**本会话最近一批**方向；隔了很多天记不清就重新"来一批新方向"

## 四、出问题怎么办

1. **没回音超过5分钟** → 截图发我（附你发的原话）
2. **回了报错文字** → 原样截图发我
3. **不要**自己重启服务器或改控制台配置——服务挂了会自动拉起，改坏了反而难查
4. 我远程看日志的入口：`journalctl -u zexin-print-agent`（这条是给我自己记的，你不用管）

## 五、验收过了之后，转给同事的三件事

> ① 飞书路由别名表（feishu_router.py 的 CAPABILITY_ALIASES）加两行："印花"→print_design、"新方向"→print_design，客户就不用打 /调用 前缀了；
> ② nginx 对 /operator/* 的 POST 请求返回 404（GET 正常），控制台网页里所有"新建/保存"按钮实际是坏的，麻烦查一下 nginx 配置；
> ③ 泽鑫要单开租户+专用飞书群（多租户是现成功能），业务和测试分开。

## 六、费用心里账

每次"来一批新方向"= 1次文字生成 + 2张图；每次"要N"= 1次文字生成 + 1~2张图。按平台之前的用量水平，正常试用烧不了多少，但守则里的"供应商侧设月度上限"记得让同事落实。
