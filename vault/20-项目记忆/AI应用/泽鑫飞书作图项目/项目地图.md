# 泽鑫飞书作图项目 · 项目地图

## 项目定位
给客户泽鑫做的印花设计自动化流水线。飞书平台跑主 agent 当调度大脑，子 agent 分工干活。总规划分三个项目：
- **项目-1（当前唯一推进）**：后台服务器 + 飞书主 agent + 四个子 agent

- 项目-3：小程序——未启动

## 技术栈
- Docker Compose（compose.cloud.yaml）+ nginx 1.24 反代（Ubuntu 自带包）
- 控制台是单页应用（app.js/app.css），多租户设计（服务商管多个客户的智能体），10 个模块：总览、商家（租户）、任务、能力、产物、交付、自动化、反馈、系统、路线图
- 只有 HTTP（80 端口），没配 HTTPS
- 后端 API：`Authorization: Bearer <运营令牌>`，主要接口 `/health`（免鉴权）、`/operator/dashboard`、`/operator/tenants`、`/operator/plans`、`/api/tasks?limit=N`、`/operator/capabilities`、`/operator/artifacts`、`/operator/delivery-center`、`/operator/automations`、`/operator/feedback-reports`。不走浏览器时用 curl 查这些接口最快
- 模型接入：文字 apimart/gpt-5.6-luna 等4家，生图 apimart/gpt-image-2（2026-08-13 时点）
