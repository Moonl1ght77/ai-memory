# Joe工作台 · 踩坑记录

## 已确认问题
- **规格表式风格卡片打动不了 Joe**（2026-10-12）：Oil UI Pro 风格卡片只有色块、字体名和平板按钮，Joe 评价"没有标新立异、按钮普通、不舒服"。给 Joe 定风格要直接出整屏真实效果图。
- **Impeccable 工作界面模式会把布局压回常规后台**（2026-10-12）：它规定工作类界面只许换配色、字体和一处特色，5 张方向图都是"左侧栏 + 卡片"换皮，Joe 仍说不好看。Joe 要强风格化时，不走这条规则。
- **Impeccable 选择页在应用内浏览器面板收起时会判成"页面关闭"**（2026-10-12）：`serve-question --wait` 退出码 4，没拿到选择。退路：图片直接发在聊天里，用提问工具让 Joe 选。

## 失败方案
- 用形容词或规格卡问 Joe 要什么风格：问不出来。先出多张差异很大的整屏试样，让他指。
- 只换材质、颜色不换骨架的「干净版」被 Joe 嫌大众（2026-10-12，85、86–89）。他要的风格化包括排版、按钮、顶部导航、侧边导航和标志写法。几个方向之间，骨架、导航方式、对象样子、标志写法都要拉开，不能都用「左上角标志、顶部标签、左侧栏、表格、右侧详情」这一套。
- 风格阶段 Joe 说「做成××」「要带交互」，直接做了可交互原型（2026-10-12），Joe 说太快了，他只要预览图。风格没点头前，一律先出整屏预览图放进总览页；交互画成图里的状态（悬停、选中、弹窗）。他看过图点头后，才做可交互原型。

## 风险
- 两套账本：工作台若另存一份进度，会和记忆库对不上，又回到"忘了做到哪"。
- 文件架核心若引用工作台层或记忆库的代码，将来拆不出来单卖。
- 游戏风试样里出现过别家角色（茶杯头、避难所小子、小骑士）和商标（IE、Windows 标志）：正式版不能用；要卖时素材、字体都得自有或开源可商用。

## 规避策略
- 出图提示词要列全所有真实项目名和类目，否则 gpt-image 会自己编项目、编标签、编摘要（2026-10-12 多张试样出现过）。提示词里写「and more / 还有更多」必出假项目（90、93 第一版编了十几个），要写「exactly these N and no others」再列全。
- APIMart 出图脚本 `design\tools\apimart-image.mjs`：密钥只读环境变量 `APIMART_KEY`；两台电脑上 Node 都能直连 APIMart（2026-10-12 实测）；查余额接口没有 `data` 外层；Windows 上 fetch 之后调 `process.exit` 触发过 libuv 断言（当时开着 `NODE_USE_ENV_PROXY=1`），脚本改成自然结束就好了。
- gpt-image-2.5-flare，3:2、2k、high：每张约 0.045 美元，24～39 秒，中文渲染清楚（2026-10-12 实测 40 余张）。
- 游戏风提示词只写游戏类型、不写作品名，并注明 original designs only：第 9 批 8 张里没有别家角色（2026-10-12，只验过这一次）。
- 更新总览页：Artifact read 带 `path` 取回的 index.html 带着发布外壳（doctype、head、body），去掉外壳再发布；配图路径写长路径 `C:\Users\Moonl1ght7\...`，短路径 `MOONL1~1` 会被读取权限规则拦下（2026-10-12）。
- 按记忆提交算项目活跃度时，排除一次改 7 个以上项目的批量提交（10-12「卡片摘要上线」改了 23 个项目，07-07 记忆系统 2.0 改了 22 和 29 个）。不排除的话，97 天没动的项目也会显示「今天有更新」。普通提交只涉及 1–4 个项目（2026-10-12 统计近 120 天）。
- 公司机的 Codex 命令行不在 PATH：它随 Codex 桌面版装在 `%LOCALAPPDATA%\OpenAI\Codex\bin\codex.exe`；Claude Code 是 npm 全局装的，在 PATH 上（2026-10-12 公司机核实，家用机未查）。软件拉起 Codex 时要自己找这个路径。Codex 官方文档已从 developers.openai.com 跳到 learn.chatgpt.com，网页抓取超时，参数以本机 `codex --help` 为准。
- 看抖音视频（2026-10-12）：agent-reach 没有抖音通道，用应用内浏览器开公开视频页 `douyin.com/video/<id>`。面板收起时页面不可见，一直停在「视频数据加载中」，截图也超时，要请 Joe 把浏览器面板打开。打开后先从页面里读「章节要点」（带时间点的分段摘要），再点「网页全屏」（快捷键 Y），用脚本暂停并跳到各时间点逐帧截图。10-13 补充：面板收起时，用脚本把 `document.visibilityState` 改成 visible 能让页面加载，但视频帧只在面板显示时才稳定解码。截得最清楚的做法：视口设成 768×1366，跳到目标前 0.6 秒、静音播 0.65 秒再暂停，把视频画到一块铺满视口的画布上再截图（盖住视频时浏览器会停止解码，所以每次跳转前先藏起画布）。仍有部分帧不刷新，用章节要点的文字兜底。
- 跨会话更新深紫原型（2026-10-13）：Artifact 要求先用 Read 逐行读完线上版本（约 700KB、4500 行）才允许覆盖，否则拒绝发布。这次派子代理读完再发布，子代理用了约 74 万 token。同一会话里用同一文件路径重发不受这个限制；给数据瘦身（文档摘录占大头）也能降成本。
- 本地预览深紫原型（2026-10-13）：浏览器面板打不开本地文件，用本机 `.claude/launch.json` 里的 prototype-preview（python http.server 服务 `.preview/`；这两样只写进 `.git/info/exclude`，不进仓库）。生成页开头要补 doctype、`<meta charset="utf-8">` 和移动端 viewport，否则中文乱码、手机模拟按 980px 排版；线上发布外壳会自动补这些。
