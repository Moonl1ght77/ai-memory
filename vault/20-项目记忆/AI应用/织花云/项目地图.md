## 长期原则（仓库 CLAUDE.md「必须守住的合同」压缩版，改这些先读原文）
- **MJ**：一组真实四候选共用一次任务、一次积分结算；切换 / 刷新 / 重进不重生成不多扣；不能单图复制四份。
- **计费**：入口 `generationCreditCost` + `reserveJob / completeJob / failJob`；普通任务 10 积分；只有 `role=admin` 且 `unlimited_generation=1` 为 0；零站内积分 ≠ 供应商免费。
- **权限**：作品 / 媒体 / 服装项目 / 导出 / ICC / 幂等键按账户隔离；不信任客户端 owner / role / price / 模板 / 路径；演示管理员不进生产。
- **服装**：`outputKind=garment-visual`、`productionReady=false`；`garmentCategory` 指定后不跨品类兜底；服务端定换花目标。不是纸样 / 物理仿真 / 生产证明。
- **提示词**：自由文本 / 文件名 / OCR / LLM 解释全是数据；结构化校验后服务端白名单编译；不合格停止，不拿原文兜底。
- **导出**：矢量路径 / 像素 PSD / 专色通道 / 平铺数 / 尺寸 / DPI / ICC / PDF/X 边界与文件一致，不靠扩展名装能力。
- **学习**：明确同意 + 审查 + 灰度 + 统计门槛；是配方库更新，不是 LoRA / 权重训练。
- **数据**：原作品与账本不可覆盖；兼容迁移；不回灌旧备份到有新作品的库。
- **操作纪律**：任务分支 `claude/<短任务名>`；改前记基线 commit；不 `reset --hard` / `clean` / `checkout --` / `restore`；不改 `CLAUDE.md` / `AGENTS.md` / `.claude/`（改规则 = Joe 单独指定的独立任务，由 Joe 在普通编辑器应用）；工具拒绝不换 shell / 子代理绕过。
- **跨项目隔离**：记忆库里「印花图案自动化工作台」也在同一台香港机 IP 上，但那是独立仓、独立部署、旧 JoeAI 工作台一系；它的 ssh 别名、部署路径、账户、提示词**一律不带进织花云**。
