# 织花云 · 踩坑记录

## 已确认问题
- **同 IP 不同项目**（2026-09-14）：记忆库「印花图案自动化工作台」记着 `ssh joeai-hk` / `admin@8.218.99.81`，和织花云线上是同一台香港机 IP。仓库 `CLAUDE.md` 明令不得跨项目带入服务器信息。规避：织花云的 SSH 方式只认 Joe 在本项目里单独给的，记忆里的别名不算。
- **桌面版会话跑不了 `/status` `/permissions` `/memory`**（2026-09-14）：`CLAUDE_GUARDRAILS.md` 的首次核对清单在 Claude 桌面 Code 会话里没法逐项执行。规避：用实际拦截当证据，PowerShell `Test-Path .env` 被工具层拒绝（报「may only access files in the allowed working directories」）即 deny 生效。
- **`npm test` 固定 1 个 skipped 不是回归**（2026-09-14 实测）：`independent psd-tools verifies zero-ink RGB process planes and exact native SPOT channels` 需要 Python `psd-tools` 并设 `PSD_TOOLS_PYTHON`，本机没装就跳过。文档说的「266 项通过」= 265 pass + 这 1 个 skip。要做专色 PSD 相关改动时才值得装。
- **bypass 模式下 deny 仍拦、ask 不弹**（2026-09-14 查官方 permission-modes 文档，原句「Deny rules block in every mode, including bypassPermissions」「Allow rules have no effect in bypassPermissions」）：Joe 09-14 删掉仓库 `disableBypassPermissionsMode`（auto 锁保留），原因是弹窗里英文命令和 diff 他看不懂、拦截等于盲签。开 bypass 后 `.env` / 数据库 / `reset --hard` / 强推 / 改 `CLAUDE.md` `AGENTS.md` `.claude/` 仍被拦；push / ssh / docker / 装依赖 / 部署脚本不再问。规避：这类动作前在对话里先用中文说明再做，不靠弹窗。改 `.claude/` 只能 Joe 在编辑器动手，Claude 被 deny 且不绕。
- **公司机跑供应商脚本必须显式传代理，node 不读 `HTTPS_PROXY`**（2026-09-14 实测）：直连 `api.apimart.ai` 超时（curl `--noproxy '*'` 15 秒 http=000），走本机代理 `http://127.0.0.1:10808` 0.9 秒返回 401。curl 自动读环境变量所以能通，undici/node 不读，脚本报 `fetch failed`。规避：跑 `scripts/*live.mjs` 或 `check-provider.mjs` 时在命令前加 `APIMART_PROXY_URL=http://127.0.0.1:10808`（或 Joe 自己写进 `.env`），Claude 不写 `.env`。服务器上直连时留空。
- **`.env` 只能 Joe 自己填，key 不进对话**（2026-09-14）：Joe 曾直接把 key 贴进对话，Claude 按规则拒绝写入、不复述，建议事后到 APIMart 后台重置该 key。可行的填法：Joe 在 PowerShell 执行 `Add-Content -Path "<仓库>\.env" -Value "APIMART_API_KEY=<key>" -Encoding ascii`，追加在末尾即生效（dotenv 同名键取最后一条）。核对是否填进去只看文件大小（例子 883 字节，填后 952 字节），不读内容。
- **AI 图描摹别用 16 色精细档**（2026-09-14 实弹 5 张 gpt-image-2.5）：`traceArtwork` 的 fine 档（1536 px、pathomit 4）会把生图自带的细颗粒描成 2.6–4.4 万条路径、SVG 2.5–3.6 MB，视觉反而出现麻点；8 色 balanced（1024 px、median 3×3、pathomit 8）1.4k–7.5k 条路径、87–747 KB，肉眼几乎无差。规避：对 AI 生图默认 8 色 balanced；「碎片路径」是量化边缘的小色岛，占路径数 76–96%，交付前需去斑（描摹器缺一个按面积过滤小路径的步骤，是产品改进项，不是脚本问题）。
- **Claude Code 2.1.207 低于文档建议版本**：官方 Read deny 联动 Edit 需 2.1.208+、Write 需 2.1.228+。本仓库配置显式写了 Edit deny，实际不受影响；升级客户端不是本项目任务。

## 风险
- `deploy/cutover.sh`、`backup-legacy.sh`、`rollback-legacy.sh` 是 2026-09 首次替换旧 JoeAI 入口的脚本，引用旧站容器；拿它们升级当前版本会出事。日常只用 `publish-release.sh` / `rollback-release.sh`。
- `npm start` 会加载 `.env`；本机没有 `.env` 时先从 `.env.example` 复制，别把生产 key 拷进来调试。
- 服务启动会把遗留进行中任务标失败并退站内积分，但不取消远端供应商任务；已有 provider task ID 先查状态再决定，别因客户端超时重发付费生成（`ARCHITECTURE.md`）。

## 规避策略
- 开工三步：`git status --short` + 分支 + HEAD → 读任务模块与测试 → 记基线 commit 后在 `claude/<短任务名>` 分支改。
- 未提交文件要覆盖前先复制到 `data/backups/<任务>/`（被 git 忽略）。
- 交付前 `git diff --check` + 相关测试 + `npm run build`；没跑的写 `not-run`，不写通过。
