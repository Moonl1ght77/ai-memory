# 元提示词agent 项目地图

## 项目定位
`元提示词agent` 是一个独立项目，用来沉淀电商生图提示词工作流 Agent。

目标用户是为电商公司生成主图、详情图、场景图和局部修复图的生图师。当前重点是把商品资料、参考图、客户规则和类目经验整理成分步骤的图生图提示词工作流。

第一版不做后台、不接模型 API。它先提供可复制的系统提示词、使用手册、知识库模板、批量字段模板、示例和可视化页面。

## 项目原则
- 每次继续任务先检查 Git 状态。
- 先读 `使用手册.md` 和相关知识库文件，再改内容。
- 不写入 `E:\AI-Memory\vault`，除非 Joe 明确要求做长期记忆更新。
- 成功交付后要沉淀成功案例；使用不舒服时优先改模板、规则或手册。
- 不把完整客户素材、图片资产或一次性聊天过程写进记忆库。
- **新商品先拍再做**：每款都要有实拍整体图 + 纹理特写图，再开始生成。
- **先判断面料类型**：第一眼仔细看原图是否有提花/花纹/肌理，不要默认素色。
- **纹理措辞用 subtle**：不要过度强调纹理，避免爆裂纹。
