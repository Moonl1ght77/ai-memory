# 面料小程序毛坯库 · 踩坑记录

## 已确认问题
- **新仓库不会自动进克劳德 App 授权**（2026-08-10 实测）：App 装的是「Only select repositories」模式时，新建仓库后建 routine 报 HTTP 403 `You don't have access to a repository this routine uses`。修复：https://github.com/settings/installations → 克劳德 → Configure → Repository access 加勾新仓库。每建一个要给云端用的仓库都要走这步。

## 风险
- 毛坯代码全部未经微信开发者工具/真机验证，「按规范推演」的观感和真实渲染可能有偏差——preview.html 只是近似
- 云端 routine 通用坑（cron 最短 1 小时/UTC/API 删不了/时间抖动/沙箱只放行 WebSearch）记录在「工作室整理总控 · 踩坑记录」，不在此重复

## 规避策略
