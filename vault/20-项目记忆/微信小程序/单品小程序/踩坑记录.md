- 微信开发者工具 RC `2.02.2607271` 升级后，若 `app.json` 报找不到 `pages/.../index.js`，先核对对应 `.ts` 源文件和 `useCompilerPlugins: ["typescript"]`；两者都在时不要手工生成 `.js`，在 `project.config.json` 显式设 `useCompilerModule: false` 回退旧编译器。2026-08-04 单品实测：重新编译后首页 Webview 恢复，`npm test` 25/25。
- 新增 TypeScript 模块后开发者工具若仍报 `module 'domain/xxx.js' is not defined`，先手动点一次“编译”让工具注册新模块；2026-07-24 季度轮播接入时复现并验证。
- 小程序 WXSS 不允许用 `.父类 swiper-item` 这类标签选择器；会报 invalid selector，并可能让轮播区域空白。应给 `swiper-item` 显式类名后只用类选择器；2026-07-24 已加契约测试防回归。
- 3D Coverflow 不能只在 `bindanimationfinish` 后切“中心/侧边”静态 class，否则拖动阶段仍是普通平移，落位后才跳变。2026-07-24 已验证：用 `bindtransition` 的 `dx` 计算连续相对距离，再同步插值缩放、旋转、模糊和遮罩；三张卡的少量视图状态更新在模拟器可稳定运行。

- Coverflow 侧卡翻转方向由 rotateY 符号决定：`rotateY = 相对距离 × 正角度` → 侧卡朝外翻；乘负角度 → 朝中心收拢。2026-08-02 单品季度轮播实测确认。
- **内置组件的 `style` 属性不可外部覆盖**：`<swiper-item style="...">` 会冲掉 swiper 内部写在 style 上的定位样式，整排卡片塌到左边缘、中心卡消失。需要给内置组件动样式一律走 class（本项目用 `.season-swiper-item.is-front` 控层叠，wxs 里用 `addClass`/`removeClass` 交接）。2026-08-02 亲手踩中并修复。
- 每个 `swiper-item` 若设了 `perspective`，它就是独立层叠上下文，写在卡片上的 `z-index` 跨 item 完全不参与比较，只按 DOM 顺序叠 —— 表现为左侧卡永远被右侧 item 压住、往左滑时"消失"。层叠必须提到 item 这一层。
- `skip-hidden-item-layout="{{true}}"` 会丢掉未显示滑块的布局信息。用 previous-margin / next-margin 露出侧卡的轮播不能开它，否则侧卡时有时无。普通全屏轮播（hero、工厂）开着没问题。
- 轮播逐帧动画不能走逻辑层 `setData`：`bindtransition` 每帧 setData 刷卡片样式，手感明显跟不上手指。正解是 WXS 响应事件，在视图层 `selectAllComponents().setStyle()` 直接改，逻辑层只管落位后的静止态。2026-08-02 单品季度轮播验证。
- 逐帧只改 transform / opacity 这类合成属性；`filter: blur()`、`background` 是重绘属性，逐帧改必掉帧。侧卡虚化改成落位后 setData 设一次 + CSS `transition: filter 420ms` 平滑跟上。
- WXS 只支持 ES5 子集：写了尾逗号或调用类型转换函数会导致开发者工具报「编译 .wxml 文件错误」（错误报在 wxml 上，实际炸的是 wxs）。取数字用 `x * 1`。项目已加测试扫描（尾逗号 / const、let / 箭头函数 / 模板字符串 / 类型转换函数调用）。
- circular 轮播跨界时 `bindtransition` 的 `dx` 会给出跨越多张的位移，直接 clamp 到 ±1 会让方向和幅度都错。要先把 `dx / 单张宽` 折回 ±总数/2 再限幅。
- 卡片改成正方形（244rpx）后，原来给 520rpx 长卡设计的文字块（padding 30rpx、标题 34rpx、规格两行）会盖住大半张卡；缩到 padding 16rpx / 标题 25rpx / 规格单行省略才留得住图。改卡片比例时必须同步缩文字块。
- 已有 WXS 驱动的 3D Coverflow 需要自动播放时，优先直接启用同一个原生 `swiper` 的 `autoplay` / `interval` / `duration`，继续复用 `bindtransition` 和 `bindanimationfinish`；不要再给卡片叠一套页面计时器或第二种 3D 动画。2026-08-05 单品实测：3000ms 间隔、650ms `easeOutCubic` 可连续自动切换，手动拖动后仍会续播。
- 云开发资源突然全部不可用、云控制台不能新建文件夹时，先查环境服务状态和套餐到期时间，不要先怀疑本地文件丢失。2026-08-04 本项目确认是个人版云开发环境到期导致隔离；续费恢复后原云端文件仍在，说明“资源不可访问”不等于“资源被删除”。
