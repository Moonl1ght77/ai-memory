# 单品小程序 · 踩坑记录

## 已确认问题
- 2026-07-19 接入记忆时发现：git 仓库只有模板的 "Initial Commit"，全部客户化改动未提交、无远程——机器一坏改动全丢。属流程坑：从模板建项后没有先建立提交习惯。（当天已解决：远程 Moonl1ght77/-feel- 建立并推送）
- hero swiper 视频用 `wx:if currentHeroIndex==index` 按需挂载 → 幕间过场时下一幕视频还没挂载，露出 poster 占位图，看着像跳转坏了。解法：视频常驻挂载，videoContext 统一调度播放/暂停（2026-07-19 模拟器验证通过，真机待复验）
- 目录扁平化前，开发者工具打开 `E:\Projects\单品` 外层会自动生成空壳 project.config.json（无 miniprogramRoot、TS 插件没开），模拟器报"找不到 app.json"，当时必须打开 `老钱小程序` 子目录。2026-07-19 代码上提后，现项目根已改为 `E:\Projects\单品`。
- 新增 TypeScript 模块后开发者工具若仍报 `module 'domain/xxx.js' is not defined`，先手动点一次“编译”让工具注册新模块；2026-07-24 季度轮播接入时复现并验证。
- 小程序 WXSS 不允许用 `.父类 swiper-item` 这类标签选择器；会报 invalid selector，并可能让轮播区域空白。应给 `swiper-item` 显式类名后只用类选择器；2026-07-24 已加契约测试防回归。
- 3D Coverflow 不能只在 `bindanimationfinish` 后切“中心/侧边”静态 class，否则拖动阶段仍是普通平移，落位后才跳变。2026-07-24 已验证：用 `bindtransition` 的 `dx` 计算连续相对距离，再同步插值缩放、旋转、模糊和遮罩；三张卡的少量视图状态更新在模拟器可稳定运行。

- Coverflow 侧卡翻转方向由 rotateY 符号决定：`rotateY = 相对距离 × 正角度` → 侧卡外缘前倾（朝外翻）；乘负角度 → 侧卡内缘前倾（朝中心收拢）。2026-08-02 单品季度轮播按 Joe“要朝外翻”翻了符号，**方向对应关系待开发者工具重新编译后由 Joe 确认，暂标假设**。
- 卡片改成正方形（244rpx）后，原来给 520rpx 长卡设计的文字块（padding 30rpx、标题 34rpx、规格两行）会盖住大半张卡；缩到 padding 16rpx / 标题 25rpx / 规格单行省略才留得住图。改卡片比例时必须同步缩文字块。

## 失败方案
- PowerShell System.Drawing 做像素级图像处理：后台会话里 Bitmap 加载挂掉（null 引用），40 万像素循环刷出 512KB 错误日志；且 GetPixel 极慢。本机图像处理一律用 `py -3` + Pillow（11.3.0 已装）：裁 alpha 边界 getbbox、缩放 LANCZOS、putalpha 着色，几秒出结果
