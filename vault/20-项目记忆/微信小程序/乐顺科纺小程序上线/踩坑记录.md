## 已确认问题
- 首建机（公司机）`python` / `python -m pip` 一律 exit 49（WindowsApps stub 损坏，与异地机同源）；可用入口是 `py -3`（Accio 3.12，`py -3 -m pip` 正常，fonttools/brotli 已装 2026-07-17）。PowerShell 下同样炸，别换壳重试。
- 产品库 `colorCards[].hex` 大量缺失：云感/微风/织境三系列去重后只剩 1 个色值（此前首页色卡墙"1 块+33"同因）。前端已做 16 色谱兜底（<8 个真实 hex 时启用）；根治=商家后台给色卡补 hex，补齐后自动切回真实色。
- 首页画册标题用的是**子集内嵌字体**（思源宋体 Bold 38 字，base64 在 index.wxss）：改系列名或板块标题必须重做子集（命令在 wxss 注释），否则新字静默回退系统字体，视觉立刻穿帮。（tab 栏的阿里妈妈方圆体子集已随 2026-07-19 经典底栏改版移除，tab 文案现用系统字体，无此约束。）
- **发布流程坑（2026-07-19 坐实）：开发者工具"上传"打包的是点击那一刻的磁盘代码**——边写边传就会把中间态发上线（7-18 正式版图注缺失即此因：上传时图注还没写完，晚上才连图注一起 commit）。规矩：先 commit+push 再上传，版本描述带提交号；排查线上疑难时先用"只有某提交才有的功能"给线上包定位版本，别信"看着没问题"。
- 乐顺的商品名是售卖艺术名不是布种名（"云皱棉"实为纯棉绉布，斜向波浪皱；Joe 2026-07-14 确认）。生图提示词写艺术名=模型瞎猜（与 agent生图项目 R12 纹理边界同源）；提示词必须写物理特征（布种/纹理形态/织法），艺术名只用于面向客户的文案层。

## 风险
- 小程序准备上线备案，任何大范围整理都可能影响上线状态。
- 未确认主版本前合并或覆盖，可能丢失后台、云函数、产品管理页面或上线配置。
- 客户证件、图片和素材如果进入 Git，可能带来隐私和仓库膨胀风险。

## 规避策略
- 先只读检查。
- 先确认上线主线。
- 高风险动作前先备份或建立 Git 基线。
- 客户资产单独整理，不和源码仓库混放。
- 每次开工先同步记忆仓库，再同步小程序仓库；遇到未提交修改时先查明来源，不自动覆盖、合并或清理。
- 图片故障要同时追踪“数据库字段 → 页面视图模型 → WXML src → 后台写回”四段；读侧兼容修好后还要验证写侧不会再次破坏旧数据。
- 对历史色卡用完整对象深比较回归测试，不能只断言图片数量或 URL，否则色号、色名和色值被改写也会假通过。
