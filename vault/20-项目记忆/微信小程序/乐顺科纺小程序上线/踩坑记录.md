# 乐顺科纺小程序上线 · 踩坑记录

## 已确认问题
- 乐顺的商品名是售卖艺术名不是布种名（"云皱棉"实为纯棉绉布，斜向波浪皱；Joe 2026-07-14 确认）。生图提示词写艺术名=模型瞎猜（与 agent生图项目 R12 纹理边界同源）；提示词必须写物理特征（布种/纹理形态/织法），艺术名只用于面向客户的文案层。
- 本机（异地机）Windows 默认 `python`/`py -3` 指向 Accio pre-install 的 3.12，进程无法创建（已损坏）；可用解释器是 uv 的 `C:\Users\Moonl1ght7\AppData\Roaming\uv\python\cpython-3.11.15-windows-x86_64-none\python.exe`。
- 本机 Node 24 下 `node --test tests/` 传目录会失败，要用无参数 `node --test`（自动发现 tests 目录）。
- CloudBase 临时地址追加 `imageMogr2` 缩图参数：已有 query 用 `&`、否则用 `?`，且不能重复追加；已封装在 `domain/media-rules.js` 的 `appendImageProcess`，别在页面里手拼。
- `wx.onShareAppMessage` 的 `imageUrl` 官方支持云 fileID（基础库≥2.8.3），清理原图直出时不要顺手删分享图。
- 开发者工具"打开 IDE"≠"开启服务端口"：CLI 自动化要看 `%LOCALAPPDATA%\微信开发者工具\User Data\<hash>\Default\.ide` 是否存在；没有就是端口没开，CLI 会无输出挂起。
- 旧版后台上传用固定云路径（`fabrics/<款号>-detail.jpg`、`<款号>-<序号>.png`），同名重传会覆盖旧文件——这就是"商家重传后旧引用变化/缺图"的来源之一；新代码已改唯一版本化路径，勿回退。
- `E:\微信小程序开发总文件` 混合了源码、知识库、客户资产、虚拟环境和 AI 工具配置。
- 该总工作区 Git 状态复杂，不适合直接 reset 或大清理。
- 商家原项目与 `client-jiajufu` 差异明显，不能互相覆盖。
- 异地电脑的项目目录名可能不同，不能只凭路径名判断是否为同一份项目；应核对 origin、分支和提交。
- 面料详情页曾在数据库对象转页面视图时漏掉主图 `img`，同时 WXML 没有主图节点；列表有图不代表详情链路完整。
- 旧 `colorCards[].file` 可能是相对文件名；若直接作为 WXML `src`，真值会绕过 fallback 并统一破图。必须保留原文件名，补成当前环境 `cloud://.../fabrics/swatches/<文件名>`，不能按款号/色号猜测实际文件名。
- 后台若把完整 `colorCards` 压成 URL 数组再保存，会永久丢失 `number/name/hex`、HTTPS 和无图色号；兼容旧引用时必须保留完整色卡对象，只规范化 `file`。
- 5116 有两个数据库引用对应的云对象已真实缺失，代码只能用色值占位，不能恢复不存在的客户素材。
- 隐私弹窗不是所有小程序首次启动都必须立即展示；平台通常在用户首次调用已声明的隐私接口且尚未同意时触发，首次打开未见弹窗不能据此判断合规与否。`a19e9a9` 起询盘表单已增加本地勾选、官方指引入口和按需 `wx.requirePrivacyAuthorize` 门槛。
- 当前项目不能按“纯展示”申报：公开路径存在询价表单个人信息入库、`wx.chooseMedia` 选图上传、`wx.setClipboardData` 复制微信号，另有商家 OpenID 保存。微信公众平台的用户隐私保护指引配置不在 Git 仓库内，必须单独人工核验并用清除授权状态后的路径实测。
- 微信开发者工具手动验收可能自动改写被跟踪的 `project.config.json`，包括 AppID；2026-07-13 已在隔离工作树复现。发现后必须先区分工具生成改动与功能代码，不得自动提交、合并或清理。

## 风险
- 小程序准备上线备案，任何大范围整理都可能影响上线状态。
- 未确认主版本前合并或覆盖，可能丢失后台、云函数、产品管理页面或上线配置。
- 客户证件、图片和素材如果进入 Git，可能带来隐私和仓库膨胀风险。

## 规避策略
- 先只读检查。
- 先确认上线主线。
- 高风险动作前先备份或建立 Git 基线。
- 客户资产单独整理，不和源码仓库混放。
- 每次开工先同步记忆仓库，再同步小程序仓库；遇到未提交修改时先查明来源，不自动覆盖、合并或清理。
- 图片故障要同时追踪“数据库字段 → 页面视图模型 → WXML src → 后台写回”四段；读侧兼容修好后还要验证写侧不会再次破坏旧数据。
- 对历史色卡用完整对象深比较回归测试，不能只断言图片数量或 URL，否则色号、色名和色值被改写也会假通过。
