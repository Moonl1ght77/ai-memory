## 代码架构（2026-07-12 起，feat/media-reliability 分支）
- DBS 分层：页面（pages）→ 服务层（`miniprogram/services/`：cloud-media-service 云存储、fabric-repository 数据库）→ 纯规则层（`miniprogram/domain/` + `miniprogram/config/runtime.js`，不依赖 wx，可 Node 单测）；`tools/media_audit.py` 为独立本地只读审计，不参与运行时。
- 图片规格唯一定义在 `config/runtime.js`（列表 720/搜索后台 480/详情 1280/色卡条 240，母图 15MB 上限）；云端永远保留高清母图，展示图实时缩图。
- 测试：`node --test`（tests/ 目录，Node 24）+ Python `unittest`（tools/tests）。

## 长期原则
- **SOP 执法（2026-07-16 Joe 授权）**：本项目按 `E:\AI-Memory\vault\30-工作流\面料小程序标准交付SOP.md` 推进。AI 每次开工报"当前所处步骤"；Joe 提出的新需求先过步骤判定，不属于当前步骤的要拦截提醒（跳步=乱的根源）；某步过关标准达成时主动宣布"第 N 步已完成"，提醒 Joe 检查验收并锁定该步不再加内容。执法条款全文见 SOP 第零节。
