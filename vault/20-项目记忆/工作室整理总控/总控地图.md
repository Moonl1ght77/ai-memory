# 工作室整理总控地图

## 用途
这是 Joe 电脑项目、知识库、客户资产整理的总控记忆。

目标是把正式源码项目、AI 记忆、Obsidian 知识库、客户资产分清楚，避免 Claude Code、VS Code、Codex、Obsidian 各自生成混乱目录。

## 整理原则
- 先盘点，不删除。
- 先确认主版本，再迁移。
- AI 工具可以读写项目，但不能让工具目录结构反过来支配项目结构。
- Obsidian 和 Basic Memory 只放知识、索引、进度和踩坑，不放源码主仓库和大量客户资产。
