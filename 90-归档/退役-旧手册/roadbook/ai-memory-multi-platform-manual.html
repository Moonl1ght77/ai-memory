Memory Operating Manual

AI 多平台记忆系统

Codex、Claude Code、VS Code 智能体都只围绕一个记忆中心工作。项目、知识库、素材各放各处，AI 只读入口和状态。

只同步项目状态入口，不同步聊天记录。

一个中心，三类资产

1

Basic Memory

路由、进度、踩坑、长期协作规则。它告诉 AI 应该读哪里。

E:\AI-Memory\vault
2

项目本体

源码、手册、模板、项目内部知识库、示例和 Git 提交。

E:\元提示词agent
E:\Projects\sku-image-workbench
E:\乐顺科纺程序
E:\实时原料看盘
3

客户素材

图片、参考图、交付图、客户资料。素材不进入总记忆。

E:\Studio-Assets\客户名\项目名

项目知识库不要搬进总记忆

留在项目里

提示词规则、追问规则、类目知识、客户知识、案例沉淀，都属于项目内部知识。

E:\元提示词agent\知识库

总记忆只记入口

Basic Memory 只记录知识库位置、什么时候更新、下次该先读哪个文件。

joe-memory/20-projects/meta-prompt-agent/context
joe-memory/20-projects/realtime-material-panel/context

完整闭环

开工

先读 INDEX，确认项目、范围和边界。

→

执行

只读当前任务需要的项目文件，不扫无关目录。

→

收尾

只把长期有用、会复用、能验证的内容写回三份记忆。

项目修改 → Git 提交 → 筛选长期有效内容 → 写入三份记忆 → 重新索引 → 验证 permalink 可读

开工三句话

A

Codex / 支持 MCP

先按 joe-memory/index 做 Memory Check。这次项目是【项目名】。
B

跨平台文件版

先读取 E:\AI-Memory\vault\INDEX.md 做 Memory Check。这次项目是【项目名】。
C

收尾同步

本轮任务结束，只把长期有用、以后会复用、能验证的内容更新到对应项目三份记忆。

三份记忆怎么分

地图

项目地图.md

项目定位、正式路径、核心资产、长期原则、固定入口。

稳定事实 长期入口
进度

当前进度.md

现在做到哪、最近提交、下一步、阻塞点、当前不做。

当前状态 下一步
坑

踩坑记录.md

失败方案、已知风险、复现条件、规避策略、验证过的修复。

已确认问题 规避策略

写入判断

长期有用 + 以后会复用 + 能被验证 = 才写入长期记忆

回到总控要不要再说

不用

完整闭环已完成

如果项目对话已经写入三份记忆、重新索引并验证 permalink，可直接结束。总控下次 Memory Check 会读到最新状态。

最新状态已经在 E:\AI-Memory\vault
需要

要核对或总览时

只有想检查写得对不对，或今天多个项目都动过、需要跨项目优先级时，才回到总控说明。

不要重复粘贴完整项目过程
项目

项目对话

负责干活、提交 Git、写回三份记忆。

总控

总控对话

负责盘点、核对、跨项目决策。

记忆

Basic Memory

负责承接所有项目的最新状态。

查

核对某个项目

我刚在【项目名】里做了收尾记忆同步，请你只读检查对应三份记忆，看写得对不对，不要改文件。
览

跨项目总览

我今天几个项目都做了记忆同步。请按 joe-memory/index 做 Memory Check，只读各项目当前进度，帮我总结现在每个项目状态和下一步优先级。
读

不重复汇报

先按 joe-memory/index 做 Memory Check。这次看【项目名】的最新状态。
验

不确定是否同步成功

我不确定【项目名】刚才有没有同步成功。请只读检查对应三份记忆和 Basic Memory permalink，告诉我是否已经是最新，不要改文件。

命

常用命令

用于排查和验证元提示词agent的记忆是否能被 Basic Memory 正确读取。

指定配置目录：后续命令都读这套 Basic Memory 配置。

$env:BASIC_MEMORY_CONFIG_DIR='E:\AI-Memory\basic-memory-config'

读项目地图：确认项目入口和长期规则。

uvx basic-memory tool read-note 'joe-memory/20-projects/meta-prompt-agent/context' --project joe-memory --local

读当前进度：确认最近优化和下一步。

uvx basic-memory tool read-note 'joe-memory/20-projects/meta-prompt-agent/progress' --project joe-memory --local

读踩坑记录：确认图片引用、防幻觉和多图规则。

uvx basic-memory tool read-note 'joe-memory/20-projects/meta-prompt-agent/bugs' --project joe-memory --local

搜索项目：确认索引里能搜到元提示词agent。

uvx basic-memory tool search-notes '元提示词agent' --project joe-memory --local
