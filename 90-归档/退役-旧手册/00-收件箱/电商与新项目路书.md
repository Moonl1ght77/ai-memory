# 电商与新项目路书

可视化页面：

`E:\AI-Memory\roadbook\电商与新项目路书.html`

双击打开脚本：

`E:\AI-Memory\tools\打开电商与新项目路书.cmd`

如果上面的中文脚本打不开，用这两个更稳的入口：

`E:\AI-Memory\tools\电商与新项目路书.url`

`E:\AI-Memory\tools\open-roadbook.cmd`

核心原则：

- 项目放项目：`E:\Projects\项目名`
- 素材放素材：`E:\Studio-Assets\客户名\项目名`
- 记忆只放路线和结论：`E:\AI-Memory\vault`

多平台记忆使用手册：

`joe-memory/quick-prompts/multi-platform-memory-manual`

可视化页面：

`E:\AI-Memory\roadbook\ai-memory-multi-platform-manual.html`

新项目启动句：

```text
这是一个新项目，先按 joe-memory/index 做 Memory Check。请帮我建立项目记忆入口，但不要移动素材和代码。
```

电商客户单启动句：

```text
这是一个电商图客户项目。请只建立项目入口和素材目录规划，不要把图片素材写进 Basic Memory。
```
